DAWN OF DECAY — Master Design Document

The single authoritative reference for what is CURRENTLY in the game — it describes the present build only (the timestamp above is bumped on every edit); the history of changes lives in the changelog. Engine: Godot 4.7, all UI built in code.

PLAYER-FACING TEXT IS GOVERNED BY THE TEXT STANDARD (docs/text-standard.html) — how every ability, status, talent, rune and glossary string is written: the two tiers (arithmetic on the draft screen and in the glossary, never mid-combat), no design rationale on a card, and the consistency rules for person, ownership, Perfect notation, keywords, duration vs cooldown, stacking, and the measured 44-character line ceiling. Every batch writes its text to it. Where this document and a description in the code disagree, the code's field is authoritative and this document is corrected toward it. What is currently non-conforming is catalogued in the text audit (docs/text-audit.html, Batch CJ), which is a report only — note that the ability descriptions in this document are NOT the strings the player reads; they are a second, independently authored copy (§0 of the audit).

1. Concept

A turn-based four-hero roguelike. The world is being consumed by the Decay; the player commands the Untouched — four heroes immune to it — through zone after zone of corrupted enemies. Runs are short, buildcrafted, and repeatable: draft four heroes, awaken permanent specializations, route a branching map of encounters, defeat the zone boss, descend deeper. Death ends the run but feeds a permanent relic collection (meta-progression). Combat is timeline-initiative with a timing skill check on every action — the player's execution matters as much as their build.

2. Run Flow

Main Menu → Draft (pick 4 heroes + equip up to 3 relics) → Spec Choice (permanent; heroes begin with no runes and three empty slots) → Map (a generated 16-slot lattice) → the node you route to: Battle, or Smith, or Trade, or ??? — with Offer (three bargains) in front of every elite and mini-boss → back to the map → … → Mini-boss → … → Zone Boss → next zone (every hero fully restored) → end boss → run complete. Talents, runes and picks are all handled on the map's hero cards; there is no separate roster screen.

A run ends in one of three ways: completion (the final boss falls), a wipe (every hero down), or a forfeit — the player abandons the run from the battle burger menu, behind a confirmation. A forfeit ends the run exactly as a wipe does (save cleared, heroes reset), so it carries no advantage; the player picks a reason from a short list, and it is recorded as a forfeit rather than a defeat everywhere it is counted. All three route into the same run summary (§11a).

  • Main menu: New Game, Continue (enabled when a save exists), Relics (collection viewer), Settings (master volume, fullscreen — persisted to user://settings.cfg), Exit.
  • Draft: heroes shown as sprite cards; click to select. Selection order = battle position (slot order also sets each hero's tint). One of each class — picking a duplicate moves it. Up to 3 unlocked relics may be equipped for the run. The Road picks the run's DIFFICULTY RUNG, and it is the run's most consequential choice: beating the END BOSS on a rung opens that tier of the meta talent tree for every spec (§7). Saved with the run. Also reachable from here: the Talents build screen, because talents are chosen between runs and the draft is between runs.
  • The difficulty ladder — three rungs. Each above the first carries a named twist as well as scaling, because stat inflation alone is a wall and a named twist is a ladder. Every scaling number below is provisional and is the designer's to set.

The final boss awards a relic unlock and big gold and ends the run — no ability pick, because nothing follows it to use one on. Fallen heroes return after a won battle at 20% max HP ("the Untouched refuse to stay down").
  • Defeat: the run ends, the save is cleared, back to a new draft.
  • Saving: auto-save to user://run_save.bin (format v8) after every completed encounter AND after spec confirmation (including debug rerolls); Continue resumes at the map. Loading swaps each member's saved tree snapshot for the live definition, so balance edits reach a run in flight, and refunds points sunk into nodes that no longer exist. A save older than v8 holds a flat 12-slot line and a single slot index, which has no honest place on a lattice — the migration would have to invent a row the heroes never stood in and a set of edges they never had — so it is refused and cleared rather than half-loaded. (Batch AN made the same call about pre-v7 saves, and Batch AI about ranked talent purchases: a wipe that says so beats a migration that invents state.) Run end (win or wipe) clears the save.

Structure rules: a run is 3 zones × 16 encounters, and then the END BOSS — 49 in all. Every zone is generated: a lattice three rows wide and sixteen slots deep. The final zone carries one extra slot after its boss.

NO NODE TYPE IS GUARANTEED ON A ROUTE. A player who routes past every blacksmith gets no blacksmith that zone — measured at 7.7% of zones under an unsteered walk. That is the design: it is what makes the trade route a choice rather than a milestone. Generation — the edges are the mechanism, not decoration

The edge graph is generated first; node types are assigned to the positions that survive. The rules:

  • Every node has 1–3 edges in and 1–3 out. Measured out-degree: 59% one, 37% two, 4% three.
  • Edges connect to the same row or an adjacent row only.
  • Paths never cross. If a node in row i reaches row j and the node in row i+1 reaches row k, then k ≥ j.
  • Nodes left with no way in or no way out are removed, to a fixpoint, so a column may end up narrower than 3. No column is ever pruned below 2 — a one-node column is a step with no decision on it, and that is guaranteed by construction (candidates that would strand a column are never in the bag) rather than by re-rolling.
  • Type constraints: no elite in column 1; no two elites in adjacent columns (and the columns run 1–14 straight through the mini-boss, so elite → mini-boss → elite is barred too); at most one of each non-fight type per column; and every entry node reaches at least one elite and at least one trade node.

Why this produces commitment without a rule: stepping down a row makes the corridor above unreachable for the rest of the half, because no edge climbs back fast enough. Measured foreclosure: 2.23 columns a node can no longer reach, on average. Nothing is sealed and nothing is announced — the geometry does it.

Decisions per run: 19.0 real choices out of 42 branching steps, where a step counts only if two or more nodes are reachable and they are not all the same type. Batch AN's line measured 0 of 2,764 on the identical definition.

The five node types

Fight nodes are battles. Hovering any node scouts it — theme, full lineup, and the band's damage-type identity ("Resists: Nature x3 / Soft to: Fire x2"), from the moment the zone is generated — and a node the heroes can no longer reach is drawn nearly out, so the cost of the last step is visible on the board. Mini-boss and boss nodes show their type but not their identity: the player learns which boss they drew only by fighting the mini-boss.

The mini-boss holds the middle of every zone. Slot 8 is an elite warband carrying a boss-tier health pool (every enemy at 1.5× its usual maximum, attack untouched — a longer fight, not a harder-hitting one). It pays elite gold (80–100) and 1 talent point, and its own spoil is a generic ability upgrade (§6a). The offer precedes it (§3a). Bosses remain fixed encounters: no modifier, no offer.

Elites are the snowball engine. An elite kill pays 1 talent point, drops a rune cache for a random hero (three candidates rolled at the kill, one chosen on that hero's card), plus a random consumable and a bigger gold purse (80–100). Six stand in a zone and a route meets two to four of them, so talent points per run are now a function of the route rather than a constant: the guaranteed floor is 2 a zone (mini-boss and boss) plus 1 for the awakening.

Blacksmith and Merchant are §8's trade nodes. Event (???) is §3b.

3a. The offer — three bargains

Before every elite and mini-boss encounter — not plain fights, not bosses — the player is shown 3 options and picks one. Since Batch BK that is 1–4 a zone rather than a fixed four, because elites are routed to rather than placed: measured 8.4 a run greedy, 8.1 balanced, 3.8 cautious (n=150 each; the count tracks how many elites the route reached, and how far the run got). The bargain is an event on the road, not a gate in front of every battle. Each option is one modifier plus one reward, both visible before choosing. There is no decline.

A modifier is a condition that binds both parties for that battle. Each carries a severity of 1–4, and the reward table reads that severity — so authoring a modifier means authoring one number, not a pairing. Severity is flat, authored per modifier, and deliberately ignores which heroes you drafted: a modifier that happens to be cheap for your build is a good deal you earned by building that way. A modifier binds every combatant on the field, including a companion summoned mid-battle.

How the three cards are dealt. The first comes from the severity 1–2 pool and the other two from the severity 3–4 pool, so every offer reads the same way: one safe option, two gambles. The floor — at least one option of severity 1 or 2 — is therefore guaranteed by construction rather than by rejecting rolls, and a wounded roster is never cornered.

The reward pays on victory: the modifier is the price, and the reward is what clearing the fight under it bought.

The pool is 20, weighted low. Because the safe slot on every card is served by the 1–2 pool alone, that is the end a run actually sees repeatedly — so it is the end that is authored deepest.

3b. Events — resource conversions in three kinds

Nothing rolls behind a cleared fight any more. The 40%-with-a-floor merchant roll and the 25% event roll are deleted: both are map nodes now, so the player can see one coming and plan to arrive with gold. The one exception is the severity-4 bargain reward "a merchant follows the fight", which is bought rather than rolled.

An event node draws one of three kinds, all sharing ONE icon (???) and one colour. The player knows an event is there; they do not know which kind. A visibly-bad node is a wall with extra steps, not a gamble.

  • Tradeoff — 60%. Two or three options, each converting one resource into another at a rate the player accepts or declines. Health for a rune, gold for maximum health, health for talent points, gold for a relic. Declining is always one of the buttons. 8 authored.
  • Boon — 25%. A straight benefit, no cost. 8 authored.
  • Bane — 15%. A straight detriment, one button, no decline. Banes are mild, and no bane may kill a hero or reduce anyone below 1 HP — a bane the player could not have avoided is only fair if it costs a resource, never a run. 4 authored: Ashfall (12% of max HP), the Cutpurse (a quarter of the purse), Spoiled Stores (two potions), Wormrot (−5% maximum health for the run).

The kind is drawn first, at 60/25/15, and the weight inside that kind picks the entry — so authoring a ninth boon does not make boons commoner.

Effects speak a fixed verb vocabulary — gold / gold_pct / heal_pct / damage_pct (never kills: floors at 1 HP) / mana_pct / max_hp_pct / attack_pct (permanent for the run, applied at battle spawn) / talent_points / item / random_item / revive_pct (the fallen return) / relic_grant (random inactive relic; +40 gold when slots are full) / rune_grant (new: a rune through the same door the elite cache uses, equipped when a slot is free) — aimed by target selectors (party, random, lowest_hp, class:<key>) and gated by requirement conditions (min_gold, max_gold, zone_slot, has_item, spec_in_party, fallen_hero). Adding an event is a JSON edit; adding a verb is one handler. 20 events ship now. Seen events persist in the save and never repeat within a run until the pool exhausts.

Not built, and the reason is worth keeping: the "a held rune for two of lower rarity" conversion needs a rune to be surrendered, and nothing in the project has ever removed a rune from a hero — equipped has exactly one writer and the pouch only grows. Building a removal path for one event would put a second, untested writer beside the one careful one.

3c. Attrition, the pouch and its slots

There is no resting. Clearing any encounter heals every hero 15% of max HP (the Chalice of Dawn relic's 10% stacks on top). Potions are usable on the map screen, not only in battle: the inventory is interactive and targets a hero from the stat cards. Four items are battle-only — the Bomb (nothing on the road to throw it at), the Cleansing Draught, the Cursed Visage and the Resonating Hourglass — and each sits in the pouch with a disabled button that says why on hover. The Defense Potion is also meaningless outside a fight and refuses with a message when pressed.

THE POUCH IS SLOT-LIMITED, AND ACQUIRING AN ITEM IS A CHOICE ABOUT WHAT TO GIVE UP. A slot holds one item TYPE and its whole stack — six Health Potions occupy one slot, not six. Slots grow with the zone: 4 → 5 → 6, announced on the zone-victory screen beside the talent-point line. The cap is the design, not a limitation: items cost no turn, so until it existed the shop only ever asked whether you could afford a thing.

  • The opening is four types in four slots — Health ×2, Mana, Bomb, Revive. The Defense Potion was dropped from the opening to make it fit; it is sold at every merchant.
  • A stack falling to zero does NOT free its slot. Only discarding it from the pouch (its own small button, confirmed) or selling it back at a merchant releases one. Both take the whole stack — a partial stack cannot be split across slots.
  • Sell-back pays 40% of the listed price, discounts included. A sale must be a loss, or the shop becomes a free locker and the cap stops meaning anything.
  • A drop with no slot is an OFFER, not a refusal: take it and give up a named stack, or leave it behind. It waits on the map, resolved by the same overlay every owed pick uses, and is saved with the run. A drop over a per-type STACK cap is still refused with a message — no room is a choice, a full stack is a wall.
  • Stack caps are per type: 6 for the five originals, 4 for the Cleansing Draught, 2 each for the Cursed Visage and the Resonating Hourglass. The shop greys a full stack rather than taking the gold, and greys a type with no slot as NO SLOT.
  • Zones — authored slots: a run is three zone slots, and each slot draws one zone from its own authored candidate pool — zones are designed FOR a position (openers are not finales), so a zone def carries its name, its boss, and a roster per slot it can host. The current pools run fixed: 1. Forest of Old (roster 1) → 2. The Scarlands (roster 2) → 3. Forest of Old as the finale (tougher roster 3 — behemoths walk the old woods). Random slot draws sit behind the DOD_ZONE_ROTATION=1 flag until each pool holds ~2 candidates; every zone keeps the same 16-slot generated shape. Deeper-slot enemies are tinted redder, and the slot sets the stat multiplier (§4.3). The finale's boss — the Withered Warden again, by design — is the FINAL boss: the run ends on its death.
  • Zone completion: killing zone 1's or zone 2's boss awards a relic unlock, gold, 1 talent point, an ability pick for every hero (§6a), and fully restores every hero (HP and Mana) before the descent.
  • Map screen: zone art background, a position readout ("Zone 2 of 3 — encounter 7 of 16 (23 of 48) — the Ash Tyrant waits"), the lattice, and all four hero stat cards.
    The cards sit on the LEFT EDGE, stacked (Batch BK), so the right two thirds belong to the map. Each carries portrait, spec name, HP bar with numbers, resource bar, three rune slots (filled or empty — click one to open that hero's pouch), an ◆N ability-upgrade count (hidden at zero; hovering it lists them as "Overpower — Honed", one per line — it takes no click of its own), and an unspent-talent badge; clicking a card opens that hero's talent tree and full sheet. An owed ability pick, ability upgrade or rune pick puts a CHOOSE button on the card which opens a three-choice overlay — the card lost 74 pixels of height in the move to the left edge and three choice buttons no longer fit inside it, and the overlay is the pattern the rune pouch already set. Each choice shows its full description under it rather than behind a hover.
    The lattice reads LEFT TO RIGHT inside a clipped viewport with a horizontal scrollbar, so the whole zone can be read before the first step. Edges are drawn. Cleared nodes are dim green and their edges gold; the nodes the heroes may step onto wear their full type colour, are larger, and are the only ones clickable; the road ahead recedes grey; and a node this route can no longer reach is drawn nearly out, which is the only way a player sees what the last step cost. Also on screen: gold, the interactive potion inventory (§3c), and the burger menu (Restart Run / Glossary / Quit to Main Menu / Quit to Desktop). There is no roster button and no separate roster screen.

4. Combat System

4.1 Initiative timeline

Every unit sits on a shared timeline. After acting, a unit's next turn arrives after delay × 100 / effective speed time units (delay is the ability's initiative cost, listed in every tooltip; basic actions are 2.0, heavy abilities up to 6.0). SETUP IS CAPPED AT HALF A SWING — 1.0. A pure buff or a shield costs no more than that, however it is authored, because a shield and a buff are both played BEFORE the blow. A HEAL IS NOT SETUP AND KEEPS ITS FULL PRICE: it answers what has already landed, so the turn it costs has been earned by the thing it answers. The floor beneath all of it is 0.5, half the setup cap again, and it is the cheapest an ability upgrade can buy. Speed 100 is average. Effective speed is what the timeline reads, everywhere — the opening roll that seeds the first turn order as well as every reschedule after it — so every modifier to speed genuinely bends the clock. Slow reduces it to 75%; Chilled to 75% at one stack and 50% at two or more, deeper still under Frigid Grip; Quick Draw raises it by 50%. Some abilities shove the target down the timeline (delay_push). The initiative bar (top of screen, 14 slots, 38×53 portraits) always shows the coming order — with one exception: an enemy held in a Cryomancer's Glacial Hold is removed from the bar entirely, because it is not going to act. Hovering any individual ability re-sorts the bar with a gold "ghost" portrait showing where that cast would land your next turn. The ghost locks in when the ability is chosen and persists through targeting and the skill check.

4.2 Skill checks

There are four cases: the normal check, the gated check, the defensive check, and the Sharpshooter's SEQUENCE. All four use the same bar and the same kind of zones — a cursor sweeps 0→1→0, stopped with Spacebar or Left Click. The first three run one 0.72s sweep; the sequence runs up to four faster ones.

THE BAR IS PARAMETERIC. The window half-widths, where the Perfect window sits, the sweep time, how many presses the check asks for, and how much each press narrows are a profile handed to the check per cast, rather than constants. One default profile is in force everywhere but one ability — ±0.045 Perfect, ±0.16 Good, centred at 0.5, 0.72s, one press, no narrowing — and it is the numbers in the table below. The Sharpshooter's basic attack is the only thing in the game that overrides it.

THE NORMAL CHECK. Every hero action runs one except the two classes of action below, which resolve at a fixed Good.

  • Actions with nothing for the grade to multiply. An ability that deals no damage and no Break damage — a pure buff, a shield, a pure debuff applier — gets no bar, because ×1.15 and ×0.6 would both resolve to nothing. Healing abilities keep their check (a heal's magnitude is multiplied by the grade), and so does anything carrying Break damage but no HP damage. A gated ability always keeps its check.
  • Basic attacks, with one exception: the Sharpshooter's basic still runs its check — and it runs the SEQUENCE below rather than an ordinary single press.

THE GATED CHECK. Five abilities do not resolve at all on a Sloppy: Death Ray (Arcanist), Requiem (Occultist), Reckless Abandon and Boil Over (Berserker), and Unleash (Beastmaster). Good and Perfect both resolve normally — the gate is Sloppy alone.

A gated failure costs the turn and nothing else. No damage, no status, no consumption: the resource is unspent, the cooldown never starts, and the meters these abilities eat are untouched — the enemy keeps its Ruin, the companion keeps its Loyalty, and the Berserker keeps his live Blood Frenzy bonus. The hero's next turn is scheduled off the ability's own delay as normal, so the punishment is tempo. The gate is shown before the cast is committed, on the ability button, in its tooltip, on the draft card, and on the bar itself while it sweeps. No healing or revival ability is ever gated.

A RECAST THAT WOULD NOT IMPROVE IS REFUSED. Re-applying a status keeps the BETTER of the two on both counts — the longer duration and the stronger power, never simply the newer one. Many powers are read LIVE at the moment of the cast (Vespers is a fifth of the Cleric's own maximum health, Magic Barrier a fifth of the Mage's, Divine Shield better than a third of the Devout's), so recasting one while it still stands can produce a smaller number than the one already on the board. The smaller number is discarded; the turn, the resource and the cooldown are not. So the cast is refused instead: when an ability's whole effect is the status it applies, and everything it could reach already holds that status for at least as long and at least as strongly, the button is dark and its tooltip names what is already standing.

The limit is deliberate: an ability that ALSO strikes, heals or converts a resource still casts even when its buff would not improve, because that half is worth the turn on its own. Funeral Pyre still smothers a fire for Mana, Stabilize still vents Resonance and heals, Battle Shout still pays its Rage, Reckless Abandon still spends the bar, and Blessing of Zeal still ticks cooldowns. 58 abilities are refusable — the pure buffs, wards and marks. Two carve-outs run the other way and never refuse: Interpose, whose charges are additive, and Divine Shield under Layered Faith, which compounds across casts rather than maxing against itself.

THE CAP IS DELIBERATE AND IT IS NOT A ROUNDING CHOICE. Focus has no ceiling, so an uncapped rule would make 400 Focus a nine-press sequence with a tightening window on his most-used action — an ability a player without the reflexes simply cannot use. Four is the ceiling; Focus keeps climbing and the sequence does not. The count is read at the moment the bar opens, from the Focus held at that instant.

PARTIAL CREDIT: every landed press counts, and a miss ends the sequence while keeping everything earned before it. A four-press attempt that misses on the second is worth one press, not zero. “Landed” means Good or better — a Sloppy is the miss that ends it.

WHAT IT PAYS: Focus. Each landed press grants 8 Focus. A full sequence — every press landed — grants a further 20 Focus on top; a partial grants its per-press Focus and no bonus. Damage resolves off the FIRST press's grade, exactly as a single-press basic does, and presses two through four add none. That keeps the change confined to the meter: a deep-Focus Sharpshooter ramps faster, he does not hit harder per swing — Focus already converts to crit chance and then to crit multiplier, so the damage increase arrives through the meter rather than beside it.

THE WINDOW TIGHTENS, BUT THE SEQUENCE DOES NOT GET HARDER. Each press is 85% of the width of the one before it, so the sequence has a shape rather than being one press repeated — and the opening window widens as the press count rises, so that landing a full sequence is about as achievable at 150 Focus as at 0. Without that, playing a Sharpshooter well would make his basic progressively harder to use, which punishes the player for the thing the spec is built to do.

His bar is the one sanctioned exception to “vary the character, hold the difficulty constant”: it is meant to be harder and to pay more. That exception is a FIXED OFFSET, not a slope — 15% less timing tolerance than everybody else's, the same 15% at one press and at four. Harder than everyone else's, not harder the better you play. His bar also sweeps faster (0.52s against 0.72s), which is what makes it feel like a different instrument; because difficulty is measured as time inside the window, the quicker sweep is paid for with proportionally wider zones and does not move the difficulty.

The bar shows how many presses are coming before the first one, and names the live press throughout (“SHOT 2 OF 4”), and a sequence that ends early says so (“CHAIN BROKEN 2 / 4”) rather than simply vanishing. The sim bot rolls its grade per press, stops at the first failure, and earns the same partial credit.

Perfect bonuses buy RELIABILITY, not magnitude, wherever an ability already carries a chance roll. On those the Perfect does not add damage or a hit — it removes the roll: Wildstrikes and Hack and Slash land their Bleed on every strike, Blizzard puts 2 stacks of Chilled on every enemy instead of 1–2, Firestorm spreads its bolts evenly across the living instead of scattering them, Arcane Barrage never strikes the same enemy twice while an unstruck one stands, Triple Shot pays out one guaranteed critical, and Pommel Strike and a perfectly rigged Snare Trap land their Stun even on an unbroken boss. Abilities with no roll to remove keep an ordinary bonus — a perfect Deadfall gets a fourth spring.

4.3 Attack resolution pipeline

Per strike, in order: ability % × the attacker's current Attack × random variance (0.9–1.1) × grade multiplier × crit (×1.5; the Sharpshooter's Lethal Aim ×2, rising with Focus) × attacker modifiers × target modifiers × (1 − resist) × (1 − effective armor), minimum 1.

  • Attack (stat) & node scaling: every unit has an Attack stat, and every ability's damage is a PERCENT of the user's current Attack (a "45%" ability at 100 Attack hits for ~45). Base Attack comes from the spec's role — Damage 100, Tank 75, Support 50 (per-spec stat blocks are being filled in class by class). All scaling is LINEAR on the base value: heroes gain +2% of base Attack and +2% of base max HP per combat node won (fight/elite/boss); enemy scaling is zone-local — each zone replays its own tier ladder at +2% of base Attack and +2.5% of base HP per tier (1–11), multiplied by the zone's slot in the run: 1st zone ×1.0, 2nd ×1.5, 3rd ×2.2 (keyed by position, not identity — the Forest of Old is ×1.0 as the opener and ×2.2 as the finale; slots past the third continue the ~×1.5 step, so adding zones never touches the formula). Armor, Resistances, Speed, Constitution, Crit, Block, and Parry never scale. Damage-over-time effects (Burn 6%, Poison 3% per stack) snapshot the applier's Attack when they land. Battle tooltips show the computed damage numbers; the hero stat page shows the numbers AND the % scaling behind them.
  • Mitigation is itemized in the log: every landed hit reports what the defenses ate — "(nature resist -8)" for resistances, "(armor -12)" for armor, and "(WEAK! +9)" when a Weakness ADDED damage — alongside the parry/block source tags.
  • Resistances (stat): heroes carry a resistance per element — Fire, Frost, Nature, Holy, Shadow, Arcane — working exactly like armor but against that damage type (negative = weakness). Hover "Resistances" on the stat page to read them; per-spec values are being assigned class by class (all 0% until then).
  • Miss: 5% base chance (single-target, non-counter only); a Dazed attacker is 20% more likely to miss, a Blinded one 50% more. Attacks against an Elusive target (Canis/Aguila) are 25% more likely to miss. AoE never misses/parries. Multi-hit and random-hit attacks roll miss per strike — a missed hit never cancels the follow-up strikes.
  • Parry: only MELEE attacks can be parried — ranged attackers (Hunter and Mage among heroes; Orc Archers and Shamans among enemies) sail past the blade. Baseline is split by side — heroes parry at 5%, enemies at 2.5% — plus parry bonuses (talents, Parry Up). A spec's stat block can replace the hero baseline outright: the Swordmaster parries at 12%, the game's only parry-STAT character, exactly as the Warden is its only Block-stat one. A parried hit still lands but with 75% less damage AND 75% less Break damage (on-hit statuses can still apply); the log names the parry's source — reflexes, Sword Mastery, or Parry Up — e.g. "(parried -75% — Sword Mastery)". Parrying does not trigger an automatic counter. AoE cannot be parried; Broken units cannot parry; multi-hit attacks roll parry per strike.
  • Counter Attack (term): immediately answering a parry — a free action with no initiative cost that cannot chain. Granted only by specific effects, all of them the Swordmaster's: Riposte and Opportunist both answer a parry with a free Overpower (a parry fires ONE counter even if he holds both), and the Untouchable capstone answers with a free Pommel Strike instead while he is in the Defensive stance. Opportunist also answers an enemy attack that MISSES.
  • Block (keyword): fully negates an incoming attack — 100% of the damage, the Break damage, and its on-hit effects. Governed by Block %, a SPEC STAT only pure tanks carry (currently the Warden: 10% base, +15% from Heavy Plating, plus Heavy Plating's climbing bonus — +8% per unblocked attack, cap +40%, reset whenever a Block lands; the Orc Shieldmaster also blocks at 5%). The Warden's Shieldwall adds a further +25% while its stance holds, on the Heavy Plating slice of the roll. Guaranteed blocks come from Interpose charges alone — one charge, one blocked attack. Broken units cannot Block. A block flashes BLOCK and the log names its source — "(Interpose)", "(Heavy Plating)", "(Bulwark Line)", or "(base Block)" — which matters: the Warden's Tenacity and Rally talents feed on Heavy Plating blocks specifically, and so, therefore, do the blocks Shieldwall buys.
  • Armor Penetration (keyword): every % of armor penetration negates a % of the target's armor (currently granted only by the Berserker's Crushing Blows talent). It is NOT shown on the character screen.
  • Adjacent (keyword): the enemies DIRECTLY next to a target in formation order, one on each side (never the target itself). A dead neighbor NEGATES the adjacent bonus on that side — the effect does not jump past a corpse to the next living enemy. Splash effects that say "Adjacent" (the Warden's Sundering) hit at most those two enemies.
  • Cooldown (keyword, "cd"): the number of the user's turns before the same ability can be used again — "6cd" means unusable for 6 turns after use. Typical bands: basics 0, light hits 1–2, heavies/AoE 2–5, Resurrection 3. The remaining cooldown shows on the ability button ("CD n") and in its tooltip. Enemies do not use cooldowns at all — their kits are gated by resources and AI conditions instead.
  • Buff / Debuff (keywords): a DEBUFF is any negative status effect, a BUFF any positive one. Talents that count debuffs (Dominant Presence, Iron Will) use this classification.
  • Crit: 10% base + 25% vs Broken targets + 1% per Arcanist Resonance stack + talent/spec bonuses (+15% with Aguila summoned). Guaranteed: Ice Lance vs Frozen; a perfect Execute. Resonance builds only on the Mage's own casts — parry counters do not grant stacks.
  • Attacker modifiers: Resonance +1.5% × N(N+1)/2 at N stacks (a COMPOUNDING curve, not a per-stack slope — see §5.1); Surge +20%; Empower +25%; Cripple −25%; Hexed −15%; Blood Frenzy up to +40%, built from HP missing AND Rage spent; Seasoned Fighter +15% above half HP; relic bonuses (global +10% dragonbone; fire/holy +20% emberheart); Powershot +2% per 1% of the target's EMPTY Break bar; Overpower +0.5 per point of target Break; Volatility +30% on Arcane Cannon; Fireball perfects at 25% of Attack. Neither Arcane Cannon nor Magi's Wrath carries a per-stack damage term — the passive compounds, and an ability-side per-stack multiplier on top of it would square the escalation. Both keep their Break terms, which ride stacks on a different axis.
  • Target modifiers: Exposed +15%; Seasoned Fighter −15% at or below half HP; Arcanist Resonance +0.75% × N(N+1)/2 damage taken at N stacks — the same compounding curve at half the step, and uncapped (the glass-cannon risk, and the whole bargain); Stabilized −10% per stack consumed.
  • Armor: flat % damage reduction. Fortify +10%; Broken ×0.7; Sunder ×0.65; Armor Penetration ignores a fraction.
  • Damage types (7): physical, fire, frost, arcane, nature, shadow, holy. Every enemy kind carries a deliberate resist AND vulnerability profile (see the bestiary §9) — themes inherit them, so a warband reads strong against some damage types and soft to others, and the theme name carries tactical information.
  • Vulnerabilities: a unit can be soft to a damage type — a negative resist, typically 25% extra damage taken from it. Hits on a vulnerability flash WEAK! over the target and are tagged in the combat log; nature-soft units also take amplified Poison ticks (and fire-soft units amplified Burn ticks). Vulnerabilities are counterplay, never hidden: they show on the map's warband hover BEFORE committing to a fight, and on every unit's nameplate hover in battle.
  • Barrier absorbs damage (not BD) before HP.

4.4 Break damage & Break

Attacks deal Break damage (BD) — damage against the Break meter — equal to the ability's Break damage (BD) value × grade multiplier (×1.5 on crits). Every unit's Break meter is a universal 0–100 scale with a numeric readout on the bar. Logged BD is the applied (post-Constitution) value, so the number always matches the meter; crits deal ×1.5 BD, which is why the same ability moves different meters by different amounts. Resistance comes from Constitution: incoming BD is scaled by 100/Constitution (100 = neutral; a 160-Constitution boss takes ~38% less Break damage; an 85-Constitution mage takes ~18% more). Constitution is set per specialization role (see §6), raised by talents and Poise runes. When the meter fills, the unit BREAKS: it loses its next turn, armor ×0.7, +25% crit chance against it, and enemies actively exploit Broken heroes with their hardest affordable attack. Bosses cannot be Stunned unless Broken (stuns fizzle with an IMMUNE flag). Breaking triggers hitstop, a purple fracture flash, and a camera punch. After the lost turn, the Break meter resets to 0. Ward halves incoming BD; the Devout's Devoutness talent cuts it 20%; Bulwark of Fortitude negates it entirely.

4.5 Bleed & damage over time

  • Bleed is a 0–100 buildup meter (chip shows Bl##). Wounding attacks add buildup (Wildstrikes 35 at 50% per target; Hack and Slash 25 at 50% per hit). At 100 the target bleeds out for 20% max HP and the meter resets. Bleedout damage ignores armor entirely.
  • Burn: 6% of the applier's Attack (snapshotted when it lands; ≈6 at 100 Atk) at the start of the afflicted unit's turn; ticks can crit using the caster's snapshotted crit chance. Burn counts as fire damage — fire resists reduce the tick and fire vulnerability raises it, exactly as nature does for Poison. Reapplication extends duration — every fresh Burn ADDS its applied turns to the running timer (a 3-turn Fireball on a burning target = +3 turns, announced with a "Burn +N turns" float).
  • Poison: 3% of the applier's Attack per stack (snapshotted; ≈3 at 100 Atk) at the start of the afflicted unit's turn. Poison counts as nature damage — nature resists reduce the tick (and nature vulnerability raises it). Stacks additively with no cap; every new application adds a stack AND refreshes the timer. Applied by Orc Archers' Poison Arrow (3 turns), the Withered Warden's Roots of Wrath (3 turns), and the Survivalist's Trapper passive (5 turns).
  • Renewal (15% of the caster's max health, snapshotted at cast) and Focus (status) +10 Mana at turn start.

4.8 Enemy AI

Enemies hunt the most wounded hero 40% of the time and pick randomly otherwise; if any hero is Broken they exploit it with their hardest affordable hit. Mocked enemies must attack the taunting Warrior — a taunt also overrides support casts. Support behaviors run before attacks: the Orc Shaman casts Healing Wave on the most wounded ally under 40% HP (friendly tanks and healers first); the Orc Shieldmaster ALWAYS casts Shielding when no ally carries its ward (lowest-HP ally first, itself included); the Withered Warden has a 60% chance to cast Wild Growth on the most wounded of its warband (itself included) when someone is below 70% HP. The Chief and the Ash-Wrought Tyrant build and spend Rage like a Warrior.

4.9 Enemy intent

Every enemy shows what it is about to do. A fight is a planning puzzle rather than a guessing game: the twelve spines that were authored around denial, patience and control — the Cryomancer's hold, the Sharpshooter's patience, the Warden's threat — are all about refusing a named action, and the player can now see the name.

Declare on schedule, resolve on turn. An enemy selects its next action the moment its turn ends, and every enemy selects once before the first turn of the battle. That stored choice is what is displayed, and it is what resolves when the enemy's turn arrives. The selection rules are unchanged (§4.8 above) — only when they run has moved.

The intent appears in two places: an icon under each enemy's portrait in the turn bar (on its next turn's slot only), and an icon plus a line on the enemy's nameplate, so a player watching the battlefield never has to read the bar. The seven categories:

The only honest number would be one produced by the same code the real hit runs, and that code cannot be run twice for the same answer — it rolls variance and a critical on the way through, and it moves the attacker's state as it goes. A number computed a second way would be a tooltip that drifts from its ability, so the category and the ability's own name are shown instead.

A declared action can be denied, and the board moves in between. Three things can happen at resolution:

  • The target is gone → the enemy re-targets within the same ability. The intent the player planned against holds; only the victim changes.
  • The ability cannot be used (its cost is no longer payable) → it falls back to the basic attack, and the combat log says so.
  • The enemy cannot act at all (Stunned, Frozen, Broken, or held by a Cryomancer) → the declared action is discarded, not banked. Denying an enemy its turn denies the action it announced, exactly as cancelling a wind-up always has.

The madness statuses are a fourth case and behave the same way: Hysteria, Bewitch and Psychosis take the turn, so the announced action does not happen.

  • Mana (Mage/Cleric/Hunter): +12 at the start of their turns; the Hunter's Perfect basic adds +10; potions/Rally restore more.
  • Focus (SHARPSHOOTER passive, NO CEILING, green second bar): +20 per consecutive attack on the same enemy (Muscle Memory and Unwavering add more), CLEARED on switching targets, up to 50 retained on a kill — all of it under Overkill. THE PAYOFF CONVERTS: the first 100 points each grant +0.5% critical chance, and every point past 100 grants +0.5% of critical MULTIPLIER instead, so ×2 becomes ×2.5 at 200 Focus and ×3 at 300. Deep Focus moves that conversion point down to 60; Spray of Arrows is the one talent that still imposes a ceiling, at 50. Spent by Coup de Grâce (which reads at most 200) and One Shot (which fires at 200).
  • Mercy (HOLY passive, 0–5): only the Holy spec has the bar. +1 stack whenever a hero falls below 50% health (any damage source; crossings count each time). Each stack held: +5% healing done. Stacks are SPENT on Hymn of Hope (1), Divine Plea (2), and Resurrection (1) — costs are paid before the cast resolves, so a spender heals with what remains — or on Empowerment: the ✦ Empower toggle (hotkey C) arms the next supporting cast for +1 extra stack and a bonus effect. Empowered casts forgo their perfect bonus. Talents move the economy and nothing else: the window that earns a stack (Guardian Angel, to 65%), the ceiling (Martyr's Vigor, to 8), the opening stacks (Zealous Light, 2), what a stack is worth (Heavenly Aura, 12% each), the refund chance (Sanctified), and the Empower surcharge itself (Ardor waives it above 3 held; Avatar of Mercy waives it always and GRANTS a stack instead). At maximum stacks a further crossing is wasted unless Grace is taken, which turns it into healing for the ally who earned it. See §7.
  • Runaway Resonance (ARCANIST passive, NO MAXIMUM): only the Arcanist spec has the bar, and it is the only resource in the game with no ceiling. Three clauses:
    • No ceiling. +1 per damaging cast, +2 on a crit (parry counters grant nothing), and nothing removes it — it persists to the end of the battle. Talents move the build RATE, never a cap: Harmonics (Arcane Explosion builds 2), Attunement (a crit builds 3), Resonant Core (+1 on the first cast of each of his turns), Critical Mass (4 on every third crit), Cascade (+1 per cast at 10 or more stacks), Backlash (+1 per hit received), On the Edge (4 for surviving below 35% health), and Overcharge (once per battle, gain half your current stacks — all of them on a perfect cast).
    • The curve compounds. At N stacks the damage bonus is 1.5% × N(N+1)/2 and the damage taken penalty is 0.75% × N(N+1)/2 — the same triangular curve at half the step. Both ends uncapped. Conduit raises the damage step to 2% and the Magi's Wrath capstone doubles it to 3%; nothing modifies the taken step. Singularity pays BUILD RATE instead — critical hits build 2 additional Resonance and every enemy killed builds 3 — because damage is quadratic in the stack count and only linear in the step, so a build-rate capstone and a step capstone come out comparable rather than one dwarfing the other. Crit building is additive: base 2, Attunement sets it to 3, Singularity adds 2 on top for 5.
    • +1% critical chance per stack, linear — one stable term that does not compound, so the tooltip has something a player can hold in their head.
    Compounding rather than linear is the whole design: a linear per-stack term is a slope, a compounding one is a curve, and the difference is what makes him nothing early and everything late. At five stacks he is weaker than a flat +15%/stack Arcanist was; by twelve he has roughly doubled. The numbers, because a compounding figure nobody tabulates is a figure nobody can plan against:
    StacksDamageDamage taken

The one thing that removes Resonance is an EARNED Stabilize, which vents everything above 2 — the escape hatch from the ramp, which is why it is a spec-pool pick rather than part of the opening three.

6a. Ability progression

Every hero opens a run with its core attack plus exactly 3 spec abilities, and earns 2 more over the run — one from zone 1's boss and one from zone 2's. The end boss awards none: the run is over and the pick would be dead value. There is no cap and no swap step, so a full run ends at core + 3 + 2 = 6 abilities.

Each award offers up to 3 abilities the hero does not already own, drawn from its SPEC pool only. Abilities are spec-locked: the class-pool draw is gone. Spec pools are 2–5 deep, so an offer shows what exists rather than padding — a hero deep into its pool may be offered two. The pick is resolved on that hero's map card, and the triple is rolled the moment the award drops — re-opening the card never rerolls it.

The mini-boss award is different in kind: a generic ability upgrade, chosen from three, attached to one ability the hero already owns. Upgrades stack on the same ability, but the same upgrade cannot be taken twice in a run. Three awards a run, one per mini-boss. 6b. THE ABILITY DRAFT

Beside the zone-boss pick sits a second, larger source of abilities: the draft. Where a boss pick is rare and drawn from a small spec pool, the draft is frequent, drawn from its own pool, and comes with a cost — a kit has room for only seven abilities, so past that point every new one replaces an old one.

Where picks come from.

SourceOffer
EliteAlways, on victory — to every living hero, each from their own pool, on one screen of four columns. Elites run 0–3 per zone, so drafts are route-dependent: a greedy route drafts far more than a cautious one.
MerchantPurchasable with gold, one hero at a time: 120 / 180 / 240 by zone. The three cards are drawn at purchase and wait on that hero's card.
EventSome events trade for one — the Ancient Training Grounds sells a new form for 200 gold, and the Echo of the Warden teaches one for a hero's health.
Zone bossesThe existing §6a pick, unchanged: same timing, same SPEC pool, same overlay.

Every offer is 3 cards, and if the pool cannot fill three it fills short rather than padding with repeats — the same rule ability upgrades already follow.

The elite draft screen. An elite victory offers a draft to every living hero at once, on one screen with four columns rather than four screens in sequence. Each hero draws their own three cards from their own spec pool and their own class pool, at the usual one-in-four seam — a Pyromancer is never shown a Warden card. A hero who fell during the fight is back on their feet before the screen opens (every won battle returns the fallen at 20% of maximum), so they draft like anyone else. A hero whose pool has nothing left to show simply has no column.

  • Declining is per hero and always allowed. One hero taking a card does not commit the others, and a settled kit is a legitimate end state.
  • A declined or dropped card does not come back that run, for that hero. The no-return ledger is per hero: refusing a card for the Pyromancer never hides it from anyone else.
  • The seven-slot cap holds per column. A hero already at the cap must name what the incoming card replaces before their column counts as decided.
  • The screen resolves as one action. All four columns are chosen, then the whole screen is confirmed — so filling the Devout's last slot can still be reconsidered before the Warden's pick is locked. Leaving the screen commits nothing; the picks stay owed on the hero cards.
  • EVERY CARD SHOWS ITS NUMBERS, NOT JUST ITS DESCRIPTION. Under each card's sentence sit its damage (as a share of Attack, with its school), its Break damage, its hit count where it strikes more than once, its heal, its cost, its cooldown, its initiative cost and its Perfect bonus. The draft screen and the glossary are the two surfaces the text standard allows arithmetic on, and this is the screen whose whole purpose is comparing cards — 30 of the 66 damaging abilities never state their damage in prose, so before this they drafted blind. The offer / drop picker on the same screen deliberately does NOT do this: it is read in the same breath as a fight, so the no-arithmetic tier binds it, and it shows the description alone.

This is four times as much drafting as one hero per elite. A hero has five spec cards and six class cards against four draftable slots, so a hero at the cap will be dropping something at nearly every elite. That is the intended shape — constant, meaningful decisions — and it is deliberately untuned: neither the cap, nor the offer size, nor the seam is adjusted for it.

The seven-slot cap, and the protected core. Every spec keeps a protected core: its passive, its basic attack, and the minimum abilities its passive needs to function. Protected abilities can never be dropped, so every drop decision is among earned abilities — which keeps the choice clean and makes the cap unable to break a passive. The core counts against the cap, so most specs carry 3 protected and 4 draftable.

At the cap, an offer becomes take-one-and-drop-one: pick the incoming ability, then name which of your earned abilities it replaces. Declining is always allowed, at any point, full or not — a settled kit is a legitimate end state, and being forced to churn would make a good build worse as the run goes on. A declined or dropped ability does not return to that run's pool, so an offer can never re-present what was just refused.

The twelve protected cores. The "needs" column is the minimum the passive cannot function without, and it varies per spec rather than following a rule: Overburn is meaningless without a Burn applier and without Detonation to spend it, so the Pyromancer's core is larger than the Berserker's, whose Blood Frenzy reads nothing but his own health bar. All four class pools hold six, so one card in four is class-wide and that seam draws a real entry for every hero in the game — no class rolls an empty pool and no offer loses its class card. The draft stands at 149 of 149 — 125 spec cards plus the 24 class-wide ones. BATCH DS CLOSED THE HUNTER CLASS GAP AND IS WHAT TOOK IT PAST 143. Its three specs held the three shallowest pools in the game (eight apiece), received none of DO's twenty-two, and not one of their twenty-four cards was a heal, a shield or hero-side mitigation — a hunter's whole defensive option set for a run was two of the six Hunter class cards. All three now read ten, matching the Cleric class, and each spec's defence is shaped by its own engine: the companion pays for the Beastmaster, the Focus meter for the Sharpshooter, the affliction board for the Survivalist. BATCH DR MOVED THAT TOTAL TWICE IN ONE BATCH AND THE NET WAS +1: Flash Freeze was retired from the Cryomancer's pool as an exact duplicate of Glacial Prison at a worse price, and the Swordmaster gained Wheeling Cut and Counter Time. TWENTY-TWO OF THE SPEC CARDS ARRIVED FROM THE TALENT TREES. A talent may not grant an ability any more — talents are chosen before the run knowing nothing, so a node that hands out a card is handing out something the player could not have planned around. The twenty-two cards those nodes granted are authored, working content, so they moved into their spec's draft pool rather than being deleted, and every one of the twenty-two cells was re-authored to modify something the hero owns in every run. No pool lost anything: the floor is still eight, nine specs are deeper than eight, and the Beastmaster, Sharpshooter and Survivalist still read exactly eight because their trees granted nothing to move. Nothing is owed. A hero who has refused his way down can still be offered two cards or one: that is the ledger of refusals working, not the draft misbehaving, and it is now the only thing that can make an offer fill short.

NINE CARDS NAME A PARTNER SPEC, AND THAT IS THE ONLY PLACE THE ROSTER IS DRAFTED FOR. Every one of the 120 cards was authored inside its own spec, so for most of the draft's life the pools never referenced each other and a draft was a decision about one hero rather than about the warband. Two accidental exceptions showed the shape worked — Fault Line hands the Sharpshooter the Break that Breaking Darkness amplifies, and Downwind copies whatever debuff an ally applied — and both are among the most interesting cards in their pools. Batch DH made nine of them deliberate. Every coupling is written on the draft card, because the draft screen is the only place the decision happens and a synergy a player cannot see is a coincidence rather than a design; and every clause is a bonus on a card that already works alone, because a run fields four of twelve specs and a card that is dead without a named partner is dead most of the time.

What the nine deliberately do not do. No new abilities (the pools are complete at 120 and a synergy card per spec would be twelve more), no new statuses (every coupling uses vocabulary already in the game), no two-way pairs (each clause runs one way into a hub, so no card is dead when its partner is absent), and no magnitude on an existing effect moves — a lone Pyromancer draws exactly what he always drew, and a Holy beside a healthy she gains exactly the 4 Mercy she always gained.

All twelve specs draft from at least eight, and no pool in the game is thin. The one hundred and forty-two drafted abilities. Each names the axis it serves, and — from the first Mage nine onward — what it builds with. The one hundred and eighteen spec cards come first; the twenty-four class-wide ones close the table.

Every ability names a combo. While a pool held two cards the question was what gap an ability filled. At eight the question is whether a build can be assembled, so each card names the talent node, the other card or the capstone it is meant to be played beside. A card that appears in nobody's build plan is a card that fills a slot.

Swordmaster — what is a stance worth. There are now two kinds of stance card, and the distinction is the rule: READERS BRANCH AND FLIP — Precision Strike and Feint read the stance, buy what the stance they leave him arriving in wants, and then switch it, so he is never stranded. GATED CARDS REQUIRE AND STAY — Sever and Battle Poise are refused outright in the wrong guard (unavailable, not weaker) and casting them moves nothing. Feigned Guard is the seam between the two.

7. Talents

TALENTS ARE PERMANENT META PROGRESSION. They are earned per spec across runs, banked forever, and spent BETWEEN runs on the build screen. A run neither earns nor spends a talent point; what it wears is decided before it starts and locks the moment a spec is confirmed.

Structure: every tree is three LANES × eight ROWS, plus a capstone shelf at row 9 — 27 cells, and all twelve specs are purpose-designed on it.

THE LOAD-BEARING DISTINCTION: BUYING A CELL UNLOCKS AN OPTION, IT DOES NOT EQUIP IT. A cell is bought once, permanently, out of that spec's banked points. Equipping is a separate act: you still pick ONE node per row, and it locks for the whole run. Owning all three cells in a row makes that row a real three-way argument; owning one leaves no argument in it.

Cells cost by tier: rows 1–3 cost 1 point, rows 4–6 cost 2, rows 7–9 cost 3. 27 cells is 54 points to fill one spec.

HERO AND ALLY ARE NOT INTERCHANGEABLE ON A CARD, AND AS OF BATCH DL THEY ARE THE ONLY TWO WORDS. A HERO is one of your four. An ALLY is a hero or a Beastmaster's companion. THERE IS NO THIRD WORD: no player-facing text uses a vaguer one any more, because a vaguer word reads as EITHER — and that ambiguity is exactly what let one card promise a shed to everyone standing and pay only the four, for the life of the project.

Six effects say ALLY and pay a companion too: Rally's +30% healing received, Hold the Line's Break cut and its no-death window, Sanctuary's heal, the Field Medic's cleanses, Harvest's reading of who opened a wound, and Rallying Shout's Pressure clause — a companion has a Break meter, so it sheds the 30 like anyone else. Everything else that reaches more than one body says HERO, and each has a reason — Rallying Cry, War Stomp and Rallying Shout's resource clause refuel a resource bar a companion does not have; Devoutness and Last Hope are stamped on the four before any companion is called; Cleansing Waters rolls once a turn and a companion never takes one; Tank and Spank's Empower would land on a companion and pay it nothing, because a companion's blows are resolved on their own path. Faith is heroes-only outright — a companion can never hold a stack. The wording tells you which you are getting, and under The Pack the difference is two extra bodies rather than one.

RALLYING SHOUT IS THE WORKED EXAMPLE OF WHAT HID FROM TWO SWEEPS: ONE CARD, TWO CLAUSES, TWO SHAPES. It sheds Pressure and refuels a resource, and the two clauses have different answers — so the card carries both words in a single sentence. Both sweeps read the ABILITY and ruled on the ability; the clause that carried neither word was invisible to each. Read a card clause by clause, not card by card.

Earning: 1 talent point per spec per ZONE BOSS defeated. Three zone bosses, so 3 points per spec per completed run — and a run that dies in zone 2 still banks 1 or 2. Only the specs among your heroes earn; a spec that did not play banks nothing. Points are per spec and never transfer, and they bank without limit. The end boss awards no points — it awards a relic, and it opens rows. At 3 a run, filling one spec is 18 completions.

Row gating is GLOBAL — it applies to every spec at once, and it is the end boss that opens it:

A tier arrives fully unlocked: beating difficulty 2 makes all nine cells of rows 4–6 buyable immediately. The reward is a place to spend, which is why banking is uncapped.

Points are freely reassignable between runs — a spent point can be pulled back and put elsewhere at no cost, any time outside a run, and a full respec costs nothing. Never during a run. Nothing is spent per run: the 54 points are a permanent unlock ledger, not a per-run budget.

Rows are themed and mutually exclusive. A row holds one node per lane; the other two are shut for that run. There is no lane requirement anywhere — a build can zig-zag or run straight down one lane. Row 8 is the node that only matters once the rest of the lane is bought: it reads an accumulated quantity the lane has spent seven rows building, removes a constraint the lane has worked around, or converts the lane's currency into something it could not previously buy. It is never a larger magnitude of a node above it.

The capstone shelf (row 9) takes one, from any lane; there is no lane-purity requirement. It is one capstone per hero, ever. It sits behind difficulty 2, so a new player cannot reach one and reaching one is the meta arc's landmark.

The build screen is reachable from the main menu and from the draft. It shows, per spec: points available, the row grid with locked / owned / equipped states, and tier costs. In a run the tree is read-only — the hero sheet shows what is equipped and says plainly that it cannot be changed.

Review aid: the map burger's "All Spec Abilities Unlocked" toggle (default OFF, session-only; DOD_SIM_GRANT_ALL=1 headless) pre-grants each hero their own spec's talent-granted abilities, capstone abilities and spec pool at spawn, so a reworked kit can be reviewed without spending points. The class pool is deliberately excluded — a sibling spec's abilities are exactly what made the toggle unusable for reviewing one spec. A class-pool ability is still reachable through a real boss reward or the debug node summoner.

Layout: every tree renders as three lane columns — seven rows deep, with a capstone shelf underneath. Lane headers count the nodes taken in each lane (a read of the build, not a requirement). Each node is an emblem square labelled with its row number, and greys out the moment it is unreachable — a row not yet open, a door a sibling shut, or a capstone before 7/7. Art is placeholder.

A row is drawn as one decision, not three picks. Each of rows 1-7 sits inside a band labelled CHOOSE ONE; hovering any node dims its two siblings, so the choice is visible at the moment it is being made; and a row that has been decided shows its siblings greyed with a lock glyph. The capstone shelf carries the same treatment under its own stricter label.

Tooltip display: a node's tooltip shows its row, its one value, what it costs and from which purse, and — for a node not yet taken — the names of the two siblings taking it would close (capstones included). A barred node names what barred it in words — "Barred — you took [Name] in this row." — and, where the surplus can still force it, says so underneath. Never a bare disabled node with no reason given.

An earned ability no longer kills its own tree node. Several abilities sit in a spec pool and in that spec's tree, so a boss can hand one over before its node is reached. When that happens the node upgrades the ability instead of granting it: either an authored effect (the Arcanist's Overcharge node buys a second use per battle) or the generic fallback — the highest-priority ability upgrade the ability does not already carry, in the order Honed → Quickened → Effortless → Swift, filtered by the same eligibility rules the mini-boss pick uses. It does not consume the once-per-run allowance on those upgrades. If every eligible upgrade is already on the ability the node grants nothing, and its tooltip says so.

Talent visibility: every talent proc is written to the combat log with a "Talent:" tag (Enraged, Unrelenting Assault, Endurance, Unkillable, Ricochet, Tank and Spank, Rallying Cry, Bulwark Line, Dominant Presence, Sundering, Riposte...), and stateful talent buffs display as status chips with live counters — Enraged / Iron Will / Crushing Blows / Battle Shout show their current % bonus, Endurance its armor streak, Shieldwall its Block bonus and Interpose its remaining charges, Bulwark Line the Block chance it lends each ally, Elemental Weakness the resist reduction, Unrelenting Assault its borrowed Constitution.

8. Economy

  • Gold: start 60 (+80 with Gravewrought Coin). Fight 45–60, elite and mini-boss 80–100, boss 110–130.
  • Talent points: NONE are awarded in a run. They are META progression (see §7): 1 per spec per ZONE BOSS defeated, banked on the profile, spent between runs. Fights, elites and mini-bosses award no talent point at all, and neither does the end boss — it awards a relic and opens the tree's row tiers. Every historical per-run figure is superseded, including 10.9 / 10.8 / 6.0 points per hero per run.
  • Combat rewards, by node type: a fight pays gold. An elite pays big gold, a rune cache and a consumable. A mini-boss pays big gold and an ability-upgrade pick. A ZONE BOSS pays gold, a relic unlock, an ability pick from the spec pool, and banks one meta talent point per spec. The END BOSS pays gold and a relic, always — no ability pick (nothing follows it) and no points.
  • Abilities: two picks per run, from zone 1's and zone 2's bosses, three offered each time and drawn from that hero's spec pool only. The end boss awards none. Each mini-boss instead awards a generic ability upgrade, three offered — three a run (see §6a).
  • Consumable prices: Health 30, Mana 30, Bomb 45, Revive 80, Defense 40, Cleansing Draught 35, Resonating Hourglass 90, Cursed Visage 100. The five original prices, starting gold and per-fight gold are unchanged — the three new lines are listings, not a re-pricing. Starting inventory: 2 Health, 1 Mana, 1 Bomb, 1 Revive — four types in the four slots a zone-1 pouch holds (§3c). The Defense Potion was dropped from the opening to make it fit and is sold at every merchant.
  • Sell-back: a merchant buys any held stack for 40% of its listed price, discounts included, and the slot comes free with it. A sale is always a loss, or the shop becomes a free locker and the slot cap stops meaning anything. A sale pays on an emptied slot too, and pays the same: the slot is what is being sold.
  • Slots are a second currency. With gold the only ceiling, everything in reach was worth buying; with 4–6 slots the merchant asks what you will give up. Two of the three new items (Cursed Visage, Resonating Hourglass) are shop-only and never drop, so what they cost is what they are worth; the Cleansing Draught is in the loot pool at a light weight.
  • The blacksmith — the gold sink (Batch BK). Batch BJ measured 63% of every run's gold going unspent, with 13.6 shop-rune refusals a run for no free slot against 6.8 for the gold reserve: slots were the binding constraint, not prices, so no amount of extra shop stock could have fixed it. A blacksmith consumes no slot. It sells the ability upgrade Batch AP already wired, three pairings on the counter, one hero each, and one purchase ends the visit — it is not a shop you clear.
    Gold only: no HP cost and no second currency, because the economy needed a pure sink. Price scales with the zone: 150 / 225 / 300. The arithmetic behind those numbers, so a later batch can argue with it rather than re-derive it: 2386 earned and 881 spent a run at 36 encounters is 1505 dead gold; at 48 encounters that scales to ~2050 before the merchant's frequency change makes it worse; six visits at these prices is 1350.
    AP's once-per-run rule does not apply here. That rule governs the mini-boss pick pool; a blacksmith is not that pool. A player may buy the same upgrade type more than once in a run on different abilities, and a purchase neither consumes a mini-boss pick nor removes that upgrade from a later mini-boss offer. The never-twice-on-one-ability rule still holds.
    Measured (n=150 per policy, all three of which rank the blacksmith at the top of their non-elite order so the question has an answer): the route walks 6.5–7.9 blacksmiths a run and buys 2.4–4.1 of them — the rest are refused for want of gold, which is a sink doing exactly what a sink is for. It converts 41–47% of all income (931 gold greedy, 904 balanced, 508 cautious). Unspent gold at run end falls from Batch BJ's 63% to 25–28%.
  • Runes (run-scoped gear, bought at the Peddler or chosen from elite caches — the in-run power source that scales with depth): an authored pool (data/runes.json). Rarity means kind, not magnitude: Common = flat stat adds (the six generated "Cracked" templates remain the filler family: +10 max HP / +2% armor / +4 Speed / +12 Constitution / +2% crit / +8 max Mana; 50g), Rare ("Polished", 100g) alters an existing ability's numbers or grants a talent-like effect (talent-counter runes STACK with the talent), Epic ("Radiant", 160g) grants an ability, changes a damage type, or inverts a rule. Scarred runes — a flag on Rare/Epic with their own prefix and colour — buy a larger upside with a real cost, and are priced below their clean peers so the trade shows in the shop. Rarity odds deepen with the zone slot: 60/30/10 → 40/40/20 → 25/45/30 (Common/Rare/Epic). Eligibility: every rune declares a scope — universal, class-wide, or spec-only, so the awakening shapes the loot table — and ability-modifying runes only roll for heroes who actually own the named ability (boss trophies included). Three equip slots, flat, from run start — no growth ladder (swapped on the hero's map card). Shop offers avoid duplicates per hero, and an exhausted pool falls back to the Common family — the offer list never comes back empty.
    Heroes begin the run with no runes and three empty slots. The first rune comes from the Peddler, an elite cache, or a severity-3-or-4 bargain. Every pick-of-three is resolved on that hero's map card, and the three are always distinct: each candidate is drawn from a pool that already excludes the ones beside it, so a triple can never offer the same rune twice. A card whose hero owes a pick wears the rune-purple border until it is spent.
    Spec coverage: 65 authored runes — 5 universal, 3 class-wide for each of the four classes, and 4 spec runes for every one of the twelve specs. Each set is built to one rule: one rune per talent lane, plus one splash that carries a term from every lane and pays for reaching outside one. Exactly one rune per set is Scarred, and it sits on a lane; splashes are always clean. The per-lane rule is what makes a rune a build decision rather than a power increment — the same rune is worth more to a hero whose points went elsewhere than to one already deep in that lane.
  • Relics (permanent meta): one random unlock per boss kill, stored in user://relics.json; up to 3 equipped per run at the draft (scrolling shelf; events can slot a run-scoped extra via relic_grant). Pool: 25 relics — 17 common, 8 rare (◆) — every effect expressed through an audited hook vocabulary (19 hooks, listed atop relics.gd: run-start gold/points/items, per-hero stat boosts at battle spawn — attack, typed damage, max HP, armor, speed, crit, Constitution, resistances, resource floor — victory heal/mana/gold, gold-find, shop discount, elite loot; the rest_heal_add hook is DEAD — rest nodes no longer exist, and the two relics carrying it, Cairnmoss Poultice and Martyr's Knucklebone, are left as written pending a design pass). Scalar hooks SUM and dict hooks merge across the equipped set, so stacking is well-defined. Adding a relic on an existing hook is pure data. Highlights: Waystone Shard opens the run with a potion of each kind; the elemental trio (Emberheart / Frostbound Sigil / Nightbloom Charm) covers all six non-physical damage schools; Prism Veil gives 10% resistance to every element; The King's Ledger compounds gold.
  • Persistent profile (user://profile.json, outside the run save): counts runs started/completed/wiped/forfeited per spec, bosses killed by kind, events seen (with repeats), and zones cleared. Forfeits are their own bucket, never folded into wipes — abandoning a run is not the same event as dying in one, and mixing them would make the wipe count unreadable the moment the exit gets used. Chronicle only — it gates nothing; the Relics screen shows the tally ("Cycles survived / lost / Events witnessed"). It is the substrate for a future persistent-unlocks design pass (sketch: persistent-unlocks-sketch.md in the workspace); sims never write to it.

11a. The Glossary

Why it exists: the tooltip culture explains numbers — a warband's resists, an ability's real damage, a talent's live value. Nothing explained a system. A player who does not know what Pressure does, or that Bleed never decays, or that relics outlive a run while runes do not, is playing a different game than the one that was built.

Shape: an authored pool in data/glossary.json read by scripts/glossary.gd — the same data pattern as Enemies / Events / Relics / Runes, so adding a term is a JSON edit and needs no code. Each entry carries an id, term, category, a one-line short (used for inline surfacing), the full long explanation, and optional see_also ids that render as working cross-links.

Coverage — seven categories: Combat flow (the initiative timeline and what delay does, the skill check, Pressure & Break, crit / miss / parry, the fallen returning at 20%), Statuses (every debuff the battle code can apply, plus Quick Draw), Damage types (all seven schools and how resists and vulnerabilities read), Resources (Rage and Mana, plus every spec resource: Resonance, Mercy, Empower, Faith, Focus, Loyalty, Ruin), Progression (the seven exclusive rows and the capstone row, the flat 1-point price, talent point income, boss trophies, ability upgrades, node scaling), Items & gear (runes, scarred runes, consumables, and relics versus runes as its own entry — permanent-across-runs versus run-scoped is the single most confusable distinction in the game), and The Run (zones and tiers, node types, elites, the bargain, modifiers and severity, events, what a wipe costs, the difficulty choice). The bargain trio was added when the modifier pool went from six to nineteen: a system with nineteen faces needs one place that explains the system rather than nineteen descriptions that each explain one face.

Surfacing: a panel from the map burger, the hero sheet, and the battle burger — a category tree on the left, the entry on the right with clickable cross-links. In battle it is inert: pure Control UI with no awaits or timers, and the battle scene suspends its own raw input handling while the panel is open so a click cannot grade a live skill check through the overlay. The timeline keeps running underneath, unchanged. Contextual entry point: a status chip's tooltip appends its glossary line when that adds information — the chip explains the effect, the glossary line names the system.

Authoring rule (load-bearing): entries are written from the CODE, at the read sites, never from this document. A glossary that teaches intent rather than behaviour is worse than none — it would make a tester confidently wrong instead of merely uncertain. Where an entry and this document disagreed, the code won and the document was corrected.

11b. First-Run Orientation & the Run Summary

Orientation — two cards, neither a tutorial mode, both dismissible and both shown once ever (gated on persistent Profile flags, set on dismissal, so a returning player is never re-taught):

  • The framing card, on the first map of a first run: what a run is — climb the tiers, the unavoidable mini-boss halfway up, the two ability picks a zone pays out, kill the zone boss, three zones, death ends the run, but a felled boss leaves a relic behind forever.
  • The skill-check pointer, at the first timing bar of the first battle: the sweeping marker, the gold and green windows, and what each grade is worth (Perfect +15% damage and +25% Break plus per-ability bonuses; Sloppy 60% damage and half Break). The design's premise is that execution matters as much as the build — a player who never notices the window is playing a materially worse game and would report it as shallow.

The run summary replaces both end panels, and serves all three endings — completion, wipe, and forfeit. It reports the outcome and depth reached ("Forfeited — Zone N …" reads distinctly from "Wiped", in its own colour, and carries the reason the player picked), the final battle (type, theme, and lineup) and which heroes fell, the heroes as they stood (per hero: spec, talent count with its lane spread, runes equipped, abilities earned), damage share per hero across the whole run, the three breakdowns below, the run economy (battles won, elites taken, gold earned / spent / unspent, rests, events seen, relics carried), and a chronicle line — cycles survived, cycles lost, and cycles abandoned once there are any — so a session of runs accumulates into something visible. A Copy summary button puts a plain-text version on the clipboard: a wipe becomes a report the player can paste back to the designer, which is feedback data with no telemetry to build. If any debug tool was used at any point in the run, the summary opens with DEBUG TOOLS WERE USED IN THIS RUN — not a clean data point. — in the panel and in the clipboard text both (see §12, Testing shortcuts).

What killed you. The summary answers three further questions, each reported for the whole run and again for the final battle alone — the run totals say what the build was doing, and only the final-battle block says what happened in that last fight:

  • Damage dealt, by ability — per hero, their top five abilities by damage across the run, with totals. The per-ability split always sums to the flat per-hero total beside it.
  • Damage taken, by source — per hero, the total and their top five sources, each named as enemy kind / ability (three Shieldmasters aggregate into one row, not three). Indirect damage is included and attributed to whoever caused it: status ticks go to the unit that applied them, and self-inflicted costs — Blood Price, Dark Pact, recoil — are marked as the hero's own.
  • The killing blow — for each hero who fell: what struck last, from whom, for how much, and what their health was before it landed. "I died" becomes "I was at 40 and it hit for 52", which is the difference between a run that felt unfair and one that taught something.

None of this is defeat-only: a completed run wants to know which ability carried it as much as a wipe wants to know what ended it.

Two structural rules behind it: (1) the summary snapshots run state before the save is cleared, never by reordering the save logic — a run that stays resumable after death is a worse bug than a missing summary. (2) The per-run ledger (damage per hero, gold, elites, rests, battles) lives on the Run autoload, not the battle scene, because the battle scene reloads between fights; it is banked once per battle from a battle-local slice, written only in real play so the simulation harness's own statistics path can never double-count it. The three breakdowns above follow both rules, and each per-hero map is bounded — at most 24 rows, with anything past that folded into a single "(other)" row — so no future ability draft can quietly grow the save file. The per-hero totals stay exact whatever the bound does to the rows.

12. Technical Reference

  • Scenes: main_menu, draft, spec_choice, map, battle, party, shop, settings, relics. All UI is built in code (no editor scenes).
  • Autoloads: Run (run state + saves), Settings, Music (looping stream player that survives scene changes; idempotent play()). Static data: Classes, Talents, Relics, Ability.
  • Saves: user://run_save.bin (auto after every node; versioned dictionary), user://relics.json, user://settings.cfg.
  • Balance tooling: DOD_AUTOPLAY=1 (one bot battle with debug prints), DOD_SIM=N (N max-speed battles + a stats report: win rate, damage shares, ability usage, roll rates), DOD_SIM_SPECS="berserker,cryomancer,inquisitor,beastmaster" (override the specs the bot plays — order: warrior, mage, cleric, hunter), DOD_SIM_ENEMIES="boss,shieldmaster,shaman" (force the enemy lineup in autoplay/sim/standalone battles), DOD_SIM_TALENTS="bz_bloodcraze:3,wd_toughness:2" (force-learn talents on bot heroes whose spec tree holds the id), DOD_SIM_ABILITIES="Resurrection,Divine Plea" (append pending talent-gated abilities to the bot hero whose spec owns them — Holy only for now), DOD_ENEMIES_OFF=1 (arm the "Enemy attacks OFF" debug toggle from the environment). Autoplay debug runs echo every combat-log line to stdout as "[LOG] ..." so headless tests can grep them; status expiries print as "... fades from ..." lines.
  • The contribution table (printed by the standalone report, the sweep and the run harness alike, so all three read the same way). One row per hero: dmg/b and dmg% (damage per battle, and its share of the heroes'), heal/b, prev/b (instrumented mitigation — blocks, barriers, stances, Faith; base armor and resists are deliberately not a contribution), BD/b and BD% (Break damage dealt, and its share of the heroes'), BDprev/b (Break damage refused or reduced), st/b (statuses landed on others), and d+h+p%.
    d+h+p% is exactly what it says: (damage + healing + damage prevented) over the heroes' total of the same three. It is NOT a share of the heroes' work. Break points and hit points are different units, and adding them needs an exchange rate nobody can defend — so Break stays out of that column entirely and gets the two columns of its own instead. A build that pays in Break (the Warden's Threat lane, the Occultist's grind, the Devout's Devoutness) reads low in d+h+p% by construction, and reading that as a weak build is the mistake the columns exist to prevent.
    Beneath the table, Break prevented per battle by source — Devoutness, Bulwark of Fortitude, Hold the Line, Ward, Immovable, Bracing — booked through one door, so the parts always sum to the BDprev/b column. Base Constitution is not booked (a stat block is not a contribution) and neither are the run modifiers Muffled and Deadened (nobody among the heroes did that).
  • Difficulty sweep: ./sim.sh --sweep N (DOD_SIM_SWEEP=1) runs N battles at EACH power budget 3/6/9/12 with a fresh warband rolled per battle from the fight-node themes, and prints — per budget — win rate, rounds, hero deaths, average enemy count, average enemies still alive entering round 3 (the field-size proxy AoE feeds on), and each hero's damage share. DOD_SIM_ZONE picks the roster, DOD_SIM_THEME narrows the roll to one theme — and because the share breakdown is per budget, a themed sweep reads out one theme's damage-share profile for free (the follow-up tool for any AoE-vs-numbers question). Sweep enemies are UNSCALED (no tier stat scaling) and sweep heroes carry base kits, so the sweep isolates the composition axis; a real tier-8+ fight is harder than its budget row. Without --sweep, plain sims fight a fixed raider/chief/archer/archer lineup (power 7, unscaled) — fine for kit smoke tests, meaningless for difficulty. Win-rate targets attach to a budget, never to "the sim": the ≈85% target describes the top of the ladder (see the changelog's Batch R sweep table for the measured curve).
    Run it at TWO build levels, because they are two different questions and each maps onto a real part of the run. Ungeared — no talents spent, the heroes as they enter zone 1: read the LOW budgets off this. All four force-learned into full 8-node lanes (DOD_SIM_TALENTS with four whole lanes) — the heroes at zone 3, where 8 points is exactly a full path: read the TOP budget off this. A single build level makes either the early game or the late game look wrong for a reason that is not real.
  • Run harness: ./sim.sh --run N (DOD_SIM_RUN=N, default 50) plays N COMPLETE runs headlessly — the real generated 48-encounter map, real warbands at real budgets WITH enemy tier scaling and the zone slot multiplier, HP/mana/items carried between battles, talent points earned and spent, elite runes and boss picks collected, all three zone slots — and prints the run report: completion/wipe rates, wipe distribution, per-slot win/death/HP averages, and the measured hero-vs-warband power table (the progression counterweight, measured instead of modelled), plus the run economy: gold earned/spent/unspent, items used and carried unused, merchants met and events fired, and which bargains the bot accepted with their average severity. The bot is dumb on purpose; every policy is printed in the report header. Its bargain policy is severity-extreme: it takes the harshest option offered while the heroes are above 60% average HP and the mildest once it is below, which exercises both ends of the table without pretending to model a payoff. DOD_SIM_ROUTE is a real axis again (Batch BK) after eleven batches in which the three policies were three samples of one walk: greedy takes every elite it can reach, cautious takes one only when nothing else is offered, balanced sits between, and all three rank the blacksmith at the top of the non-elite order so the gold-sink question has an answer. default aliases balanced and elites aliases greedy, because every old sim script names them. Shops are played by policy (heal-first: any hero under 50% HP buys a Health Potion; then the priciest affordable offer not already carried, runes included but only onto a member with a free slot, equipped at purchase; no buy dips below the 40g reserve — DOD_SIM_SHOPS=off restores the old buy-nothing floor). In battle the bot drinks a carried Health Potion when it opens a turn below 35% HP (DOD_SIM_ITEMS=off restores the never-drinks floor; sweep and standalone battles always stay dry so their baselines hold). DOD_SIM_BUILDS="spec:LaneName,..." names the talent lane each spec buys down (default: the tree's first lane, cheapest node first, capstone the moment its gate opens), DOD_SIM_TROPHIES lists preferred ability picks (default: the first offer entry), and DOD_SIM_RELICS arms relics at the draft. DOD_SIM_MAP, DOD_SIM_MINIBOSS, DOD_SIM_START_RUNE and DOD_SIM_SPEC_OPENING are retired — the dealt mini-boss row and the opening rune pick they controlled no longer exist, so a Matrix row reads map=branch (Batch BK; map=line is an AN-to-BJ row) and carries no such fields. Rows from before Batch BK are not comparable with rows after it: depth is out of 48 slots rather than 36, and choice= went from a structural 0% to a measured one. Still excluded, stated in the output: bomb/revive/defense/mana items are never used in battle, no pre-emptive or offensive item use, routing sees one tier ahead only, and shop rune picks ignore build synergy. Simulated runs live entirely in memory (Run.sim_run): they never touch the player's save, relic unlocks, or profile.
  • Testing shortcuts: debug tools are ALWAYS available in dev (unexported) builds; exported builds require DOD_DEBUG=1 (and DOD_DEBUG=0 forces the gate shut in a dev build, which is how the headless tests stand where an exported build stands). The map burger menu gains a DEBUG section — +200 gold, +200 talent points for everyone, full heal, walk to the boss slot, advance to the next zone, Reroll Specs (refunds spent talent points, clears all specs, and reopens the awakening screen), and an All Spec Abilities Unlocked toggle (while checked, battles spawn with every talent-gated and trophy ability pre-granted — session-scoped, never saved, default OFF so normal play and sims measure real gated progression; headless runs arm it with DOD_SIM_GRANT_ALL=1).
  • Reaching any node on demand. Two tools sit in the same DEBUG section. Free Travel is a check item: while it is on, every node on the board is clickable — every tier, ignoring links and ignoring where the heroes stand, backwards as well as forwards. Clicking one advances the run honestly: the heroes really move, the node is really marked visited, the tier readout reads the real tier, a fight is scaled by the tier it actually sits on, and the node books its tally and its Profile entry exactly as it would have. Nodes the toggle alone makes reachable are drawn as a fourth state, separate from visited / reachable / unreachable: a desaturated fill inside a magenta debug outline, with a [DEBUG] tooltip prefix, and a DEBUG: FREE TRAVEL marker sits in the corner while it is on.
    Test a node ▸ is a submenu — Shop, Rest, ??? Event, Fight, Elite — that runs one in place. A summoned node does not move the heroes, does not touch the tier, and does not mark anything visited; the board is exactly as it was when the tester returns. Everything else is real: a summoned shop has real offers and spends real gold, a summoned rest really heals, a summoned fight is a real battle at the current tier's scaling, with real rewards. (There is no Summon Boss: "Jump to Boss Tier" already goes there.)
  • Debug visits do not count. A summoned node is excluded from the two records that are read as data: it never bumps the run ledger (battles, gold, rests, elites, damage) and never books anything in the persistent Profile — including the wipe, if the heroes die in a summoned fight. One session flag guards all of it. Free travel is the opposite case and is deliberately excluded from this rule: the heroes really are there and really did the thing.
  • The event picker. "??? Event" does not draw an event — it lists every event in data/events.json by title and id, each row stating whether its requirements currently pass or, if not, which condition failed (read from the same check that filters the real draw, so the two can never disagree). Requirement-failing events are selectable on purpose — testing the greyed-out branches is the point, and the event screen still runs its own guards. Already-seen events are repeatable, and picking one neither burns the run's draw pool nor tells the chronicle.
  • The honesty flag. Using any debug tool, on either menu, marks the run for the rest of its life (saved with it; unchecking a toggle never clears it). The end-of-run summary then opens with DEBUG TOOLS WERE USED IN THIS RUN — not a clean data point., in the panel and in the Copy summary clipboard text both, because the summary is the alpha's feedback channel and a debug-touched run is not a data point. Simulated runs can never set it: they load neither the map nor the battle menus.
  • In battle, a DEBUG ▾ menu (bottom-right) offers: Full Restore (HP/resources/secondary for every hero), Kill All Enemies (every living enemy is switched off — no damage event, no on-hit or on-death proc — and the normal victory flow runs: gold, talent points, the heal, the bargain's reward, elite spoils and the summary), a Cooldowns OFF toggle (while checked, hero abilities never go on cooldown; existing cooldowns clear on enabling — enemies carry none), an Enemy attacks OFF toggle (enemies skip their turns while checked), and a turn lock — pick a hero and every HERO turn is theirs until you unlock (re-select them) or lock a different hero, while enemies keep attacking on their own turns (combine with Enemy attacks OFF to silence them); built for testing one hero's kit under fire. The displaced heroes' clocks advance as if they had acted, so the initiative timeline keeps flowing. The battle scene also runs standalone (godot res://scenes/battle.tscn) with a default roster and no run state.
  • Sprites: horizontal frame strips named Name_Idle/Walk/Attack01–03/Hurt/Death.png (square frames; the stock sheets are 100×100, but units accept any frame size via the frame_size config — the Berserker sheet is 124×124, the Pyromancer 236×236). Partial sheets are fine: missing Attack02/03 replay Attack01, missing Hurt/Death hold the idle frame, and a single-frame Idle (the Pyromancer today) simply stands. Dedicated portraits are Name_Portrait.png (used on the nameplate, initiative bar, and hero list). New assets arrive in "imported files/" (animated GIFs get converted to strips; 8-direction rotation GIFs — the east-facing frame is extracted).
  • Resolution template: all character art matches the Pyromancer — a standing figure ≈110–120px tall inside a 236px frame, rendered at 1:1 (never scaled), original colors. The Berserker (124px @1.25×) is legacy-sized and should be re-generated at the template when convenient. Battle backgrounds: authored at ≈1280×720 (up to ~1670×940) and shown at/near native size — never blown up.
  • Combat pacing: global PACE multiplier 0.85 on battle waits.

13. Known Gaps / Next Steps

  • Rung 1's landing zone is a cliff, and 70% sits inside it. Untalented completion reads 28% at ×0.60 and 83% at ×0.50, so one step of the multiplier is worth 55 points and the value that would land on the stated target was never sampled. The shipped ×0.50 is the nearest sampled value, not a tuned one; the finer sweep (×0.58 to ×0.52) is cheap and has not been run.
  • The ladder does not yet absorb the tree at rungs 2 and 3, and the shape of the miss is legible. Rung-matched builds read 0% at rung 2 and 18% at rung 3 while the power ratio reads a clean, monotone 1.26 / 0.91 / 0.67 — so the ladder IS steeper at every rung and it is the tree that is uneven. Rows 7–9 are where the tree's power lives, and rung 2 asks for a build that stops one row short of them. Two plausible fixes remain (the tier boundary, the capstone's price) and no measurement yet distinguishing them. Moving a rung is not one of them — the ratios say the ladder is not what is wrong.
  • A capstone is worth more than the eight lane nodes beneath it put together — eight picks and nine picks at the same rung read 8% and 68%. Measured, reported, untouched.
  • BH's leave-one-out grid is owed on Harmonic Convergence (Arcanist, Resonance row 8), the one row-8 node whose subject is a build RATE on a curve that is quadratic in the count.
  • The end boss is a PLACEHOLDER by designer decision: statted as a hard boss, a name, and no bespoke mechanics beyond the two abilities the ladder adds.
  • The re-specced Waystone Shard, Horn of the First War and three events carry provisional magnitudes — they were re-pointed because the currency they paid in was deleted, not because anyone priced them.
  • Art pipeline (Aseprite + Pixel Lab): re-generate the Berserker at the 236px template (plus his missing Hurt / Death / second-attack clips); animate the Pyromancer (currently a static pose); produce the remaining hero specs, portraits for everyone but the Berserker, real companion art for the placeholder companion spheres, and — the big lever for scenery scale — battle backgrounds authored at the template density. Own art is battle-only so far; draft/spec screens still show the Soldier.
  • Design hooks awaiting assignment: Weaknesses (who is weak to which damage type — only the Tyrant's frost weakness is set) and Counter Attack (defined term; no talent or ability grants it yet).
  • The Withered Warden has its own kit; the Ash-Wrought Tyrant is still a Chief stand-in — unique kit + art planned. Boss art for both pending.
  • Boss tri-choice class modifiers deferred until 3+ zones exist.
  • Designed BOSS-POOL abilities not yet written — FOUR, not six, and Batch DS corrected the list. The Sharpshooter's Disengage, Suppressing Fire and Piercing Arrow are still owed, and the Survivalist's Blight. Two entries were stale: Field Dressing was written at BR — as a HUNTER CLASS-WIDE DRAFT card rather than as this pool's, so the name is spent and the boss pool still has nothing by it — and Smoke Bomb's function shipped at BO as Choking Smoke in his draft pool. Both spec pools ship at five of their designed eight; the cross-fill rule keeps every offer at three without them. DS deliberately did not spend the three Sharpshooter names on its own two draft cards, which would have paid one debt by opening another.
  • Difficulty tuning is pending an honest baseline: the old "~100% win rate" figure measured a single fixed unscaled lineup and carried no information. The sweep (./sim.sh --sweep) now reads win rate per budget; tuning decisions design against that curve plus playtests. Batch BK reset every run-level baseline — 48 encounters rather than 36, a route that can be walked well or badly, and elite payouts that are now earned rather than issued — so the whole run curve wants re-reading before anything is tuned against it.
  • Is the elite paid correctly? The whole map exists to express the trade: three elites is three modifiers, three rune caches and three talent points against arriving at the mini-boss wounded. Measured at n=150 a route, greedy and balanced are indistinguishable (0.70σ on completions) and both beat cautious decisively (3.5σ and 4.2σ) — so ducking every elite is already the losing play, but whether hunting them is the winning one is below this instrument's resolution. It wants either a larger n or a policy pair further apart on the elite axis than greedy and balanced turned out to be (6.47 elites a run against 6.00).
  • A rune has never been removed from a hero. The equipped flag has one writer and the pouch only grows, which is why Batch BK's event vocabulary can grant a rune but not take one — and why the "trade a held rune for two of lower rarity" conversion is unwritten. Whenever a design wants that, the removal path is the piece to build carefully and once.
