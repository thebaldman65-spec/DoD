DAWN OF DECAY — Master Design Document

The single authoritative design reference (the timestamp above is bumped on every edit). It supersedes the original concept docs ("Dawn of Decay.docx", "DoD Combat.docx", "DoD Classes.docx", "DoD Run.docx", "DoD UI.docx", "DoD Narrative_Zones.docx") and the now-retired Implementation Addendum (frozen as a historical changelog). Engine: Godot 4.7, all UI built in code.

1. Concept

A turn-based party roguelike. The world is being consumed by the Decay; the player commands the Untouched — four heroes immune to it — through zone after zone of corrupted enemies. Runs are short, buildcrafted, and repeatable: draft a party, awaken permanent specializations, climb a node map, defeat the zone boss, descend deeper. Death ends the run but feeds a permanent relic collection (meta-progression). Combat is timeline-initiative with a timing skill check on every action — the player's execution matters as much as their build.

2. Run Flow

Main Menu → Draft (pick 4 heroes + equip up to 3 relics) → Map (node climbing) → Battles / Rest / Loot → after the first victory, Spec Choice (permanent) → Party screen (talents, runes) → … → Zone Boss → next zone (party fully restored) → final boss → run complete.

  • Main menu: New Game, Continue (enabled when a save exists), Relics (collection viewer), Settings (master volume, fullscreen — persisted to user://settings.cfg), Exit.
  • Draft: heroes shown as sprite cards; click to select. Selection order = battle position (slot order also sets each hero's tint). One of each class — picking a duplicate moves it. Up to 3 unlocked relics may be equipped for the run.
  • Spec choice: offered per hero after the first victory. Three cards per class, each showing the spec name, its archetype in bold (mouseover for the archetype explanation), blurb, passive, and full ability details. The choice is permanent for the run.
  • Victory rewards: gold + talent points for every hero. Fallen heroes return after a won battle at 20% max HP ("the Untouched refuse to stay down").
  • Defeat: the run ends, the save is cleared, back to a new draft.
  • Saving: auto-save to user://run_save.bin after every completed node; Continue resumes at the map. Run end (win or wipe) clears the save.

3. Zones & the Node Map

Structure rules: every zone is a ladder of 10 tiers plus the boss tier. Each tier holds 3 nodes — 30 interconnected nodes total — and the player picks exactly one node per tier, so 10 nodes are interacted with before the boss. Node composition is a fixed deck per zone:

TypeCountShareEffect
Fight1860%Battle vs. a zone encounter. Fights on tiers 6+ have a 25% chance to spawn as an ELITE (tougher composition, double talent points, more gold).
Rest620%Party heals 30% max HP and Mage/Cleric recover 30% Mana at the waystone.
Shop620%The Wandering Peddler: consumables + one rune offer per party member (see §8).

The deck is shuffled and dealt 3 per tier (tier 1 is guaranteed at least one fight so runs open with combat). Connectivity is deliberately limited: every node links to its own column on the next tier, plus a 70% chance of ONE adjacent column — never all three. The player gets a route choice most tiers but can only drift one column per step, so reaching a specific elite or shop takes planning; every node keeps at least one inbound path so the map never strands. The boss tier is a single node.

Elites are the snowball engine: a skilled player routes toward them. On top of double talent points, an elite kill drops a rune for a random hero, a random consumable, and a bigger gold purse (80–100).

  • Zones: 1. Forest of Old → 2. The Scarlands. Later zones multiply enemy HP and damage by (1 + 0.35 × zone index) and tint enemies redder.
  • Zone completion: killing the boss awards a relic unlock, big gold, 3 talent points, and fully restores the party (HP and Mana) before the descent.
  • Map screen: zone art background, node ladder, Party button (shows unspent talent points), read-only Inventory dropdown, burger menu (Restart Run / Quit to Main Menu / Quit to Desktop), gold + party HP readout.

4. Combat System

4.1 Initiative timeline

Every unit sits on a shared timeline. After acting, a unit's next turn arrives after delay × 100 / speed time units (delay is the ability's initiative cost, listed in every tooltip; basic actions are 2.0, heavy abilities up to 6.0). Speed 100 is average. Slow status reduces effective speed to 75%; Quick Draw raises it by 50%. Some abilities shove the target down the timeline (delay_push). The initiative bar (top of screen, 14 slots, 48×66 portraits) always shows the coming order; hovering any individual ability re-sorts the bar with a gold "ghost" portrait showing where that cast would land your next turn. The ghost locks in when the ability is chosen and persists through targeting and the skill check.

4.2 Skill checks

Every hero action runs a timing bar: a cursor sweeps 0→1→0 (0.72s per sweep); stop it with Spacebar or Left Click.

GradeZone (half-width around center)DamagePressureExtra
PERFECT±0.045×1.15×1.25Unique per-ability bonus (listed in every tooltip); AoE perfects get ×1.5 Pressure
Good±0.16×1.0×1.0—
Sloppy (miss the zones)—×0.6×0.5—

Auto-cast abilities (no target click) show a Cancel button during the check; cancelling returns to the action bar. Enemies and the sim bot always act at "Good" (bot: 20% perfect, 15% sloppy).

4.3 Attack resolution pipeline

Per strike, in order: base damage × random variance (0.9–1.1) × grade multiplier × crit (×1.5; Sharpshooter passive ×2) × attacker modifiers × target modifiers × (1 − resist) × (1 − effective armor), minimum 1.

  • Miss: 5% base chance (single-target, non-counter only). AoE never misses/parries. Multi-hit and random-hit attacks roll miss per strike — a missed hit never cancels the follow-up strikes.
  • Parry: 5% base + parry bonuses; negated hit and the defender counters with their basic attack as a free action (no initiative cost, cannot chain). Broken units cannot parry. Multi-hit attacks roll parry per strike; each parried strike triggers a counter, and the remaining strikes still land (unless the counter kills the attacker).
  • Crit: 10% base + 25% vs Broken targets + 3% per Mage Resonance stack + talent/spec bonuses (+15% with Aguila summoned). Guaranteed: Razor Ice vs Chilled.
  • Attacker modifiers: Resonance +15%/stack; Surge +20%; Empower +25%; Cripple −15%; Blood Frenzy up to +40% as HP falls; Seasoned Fighter +25% above half HP; relic bonuses (global +10% dragonbone; fire/holy +20% emberheart); Powershot +2% per 1% of the target's EMPTY Break bar; Overpower +0.5 per point of target Break; Frost Bolt 50% chance ×2 vs unchilled; Arcane Cannon +7.5%/Resonance stack; Pyroblast +25% vs Burning.
  • Target modifiers: Shieldwall −50%; Exposed +15%; Mage Resonance +10% damage taken per stack (the glass-cannon risk).
  • Armor: flat % damage reduction. Fortify +10%; Broken ×0.7; Sunder ×0.65; armor_pierce ignores a fraction (Piercing Arrow 50%, Singularity 30%).
  • Damage types (7): physical, fire, frost, arcane, nature, shadow, holy. Enemies carry resist fractions (negative = vulnerable, e.g. the Withered Warden takes +25% fire).
  • Barrier absorbs damage (not Pressure) before HP.

4.8 Pressure & Break

Attacks add Pressure equal to the ability's Pressure value × grade multiplier (×1.5 on crits). Every unit's Break meter is a universal 0–100 scale (base Stability 100 for all heroes and enemies; talents, the Bulwark passive, and runes raise it above 100) and shows a numeric readout on the bar. When Pressure reaches the unit's Stability, it BREAKS: it loses its next turn, armor ×0.7, +25% crit chance against it, and enemies actively exploit Broken heroes with their hardest affordable attack. Breaking triggers hitstop, a purple fracture flash, and a camera punch. After the lost turn, Pressure resets to 0. Ward and (removed) mitigation statuses halve incoming Pressure.

4.5 Bleed & damage over time

  • Bleed is a 0–100 buildup meter (chip shows Bl##). Wounding attacks add buildup (Wildstrikes 35 always; Hack and Slash 20 at 40% per hit). At 100 the target bleeds out for 20% max HP and the meter resets.
  • Burn: 6 damage at the start of the afflicted unit's turn; ticks can crit using the caster's snapshotted crit chance.
  • Poison: 3 damage per stack at the start of the afflicted unit's turn. Stacks additively with no cap; every new application adds a stack AND refreshes the timer. Applied by Orc Archers' Poison Arrow (3 turns) and the Survivalist's Trapper passive (5 turns).
  • Renewal +8 HP and Focus (status) +10 Mana at turn start.

4.7 Items in battle

The party inventory is shared. Using an item does not consume the turn, but each hero may use only one item per turn. Bomb: 50 damage to all enemies. Health Potion: +40 HP. Mana Potion: +40 Mana/Rage. Revive Potion: fallen ally returns at 50% HP. Defense Potion: party gains Fortify (3 turns).

4.8 Enemy AI

Enemies prefer finishing wounded heroes (65%) or spread damage randomly; if any hero is Broken they exploit it with their hardest affordable hit. Mocked enemies must attack the taunting Warrior. The Chief/Bosses build and spend Rage like a Warrior.

4.9 There is no announcer

All battle information lives in the scrolling combat log (top right) and floating combat text. No banner text appears at the top of the battle.

5.1 Resource mechanics

  • Rage (Warrior): starts at 0. +5 at the start of each of his turns; +10 whenever he is hit; every attack builds Rage (Strike 20, all spec/talent attacks 10); Perfect Strike +10. Eidolon Mirror relic: start battles at 25.
  • Mana (Mage/Cleric): +12 at the start of their turns; potions/Rally restore more. Mage Phoenix Rebirth trades HP for a full refill.
  • Focus (Hunter): +15 at the start of their turns; Perfect basic +10.
  • Faith (Cleric secondary): +10 per action taken; spent on MIRACLE abilities (no Mana cost).
  • Arcane Resonance (Mage secondary, 0–5): +1 per damaging resolve (+2 if it crit). Each stack: +15% damage dealt, +3% crit, but +10% damage taken. Hitting max triggers Backlash Ward (+15 Mana). Stacks persist the whole battle (the old Guard vent is gone).

5.2 Core kits (before specialization)

  • Warrior: Strike — 23 dmg / 18 Pressure / delay 2.0, builds 20 Rage (Perfect: +10 Rage).
  • Mage: Magic Bolt — 25 arcane / 14 Pr / 2.0 (Perfect: +10 Mana); Arcane Surge — 15 Mana, 3.0, +20% attack next turn, +1 Resonance guaranteed (Perfect: +2).
  • Cleric: Smite — 22 holy / 16 Pr / 2.0 (Perfect: self-heal 8); Mend Wounds — 25 Mana, heal 45, 3.0 (Perfect: Ward 2 turns); Renewal — 20 Mana, ally +8 HP/turn for 5 turns, 3.0 (Perfect: +8 instant).
  • Hunter: Quick Shot — 20 dmg / 14 Pr / 2.0 (Perfect: +10 Focus).

7. Talents

Each spec has a signature talent pool, tiered 1–6. Every run generates a fresh tree: 2 slots per tier, drawn from the pool and padded with generic Training talents (Vitality +HP / Swiftness +Speed / Poise +Stability / Warding +armor / Precision +crit / Reserves +Mana, values scale with tier). Tier N unlocks after (N−1)×2 points are spent in the tree. Points come from victories: fight 1, elite 2, boss 3 (Waystone relic: +1 at run start). Some talents have prerequisites and multiple ranks; tier-5 talents typically grant a whole new ability (Rampage, Bulwark Slam, Flurry, Inferno, Absolute Zero, Singularity, Sanctuary, Excommunicate, Soul Leech — all warrior talent attacks also build 10 Rage). Beastmaster, Sharpshooter and Survivalist pools are still thin (2 signatures each) and lean on Training fillers — growth planned.

8. Economy

  • Gold: start 60 (+80 with Gravewrought Coin). Fight 25–35, elite 80–100, boss 110–130.
  • Consumable prices: Health 30, Mana 30, Bomb 45, Revive 80, Defense 40. Starting inventory: 2 Health, 1 Mana, 1 Bomb, 1 Revive, 1 Defense.
  • Runes (run-scoped gear, bought at the Peddler or dropped by elites): rarity roll 60% Common (×1, 50g, "Cracked"), 30% Rare (×2, 100g, "Polished"), 10% Epic (×3, 160g, "Radiant") over templates: +10 max HP / +2% armor / +4 Speed / +12 Stability / +2% crit / +8 max Mana (per rarity multiplier). Each hero can equip 2 (toggled on the party screen); shop offers avoid duplicates per hero.
  • Relics (permanent meta): one random unlock per boss kill, stored in user://relics.json; up to 3 equipped per run at the draft. Pool (6): Waystone Shard (+1 talent point at run start), Dragonbone Idol (+10% damage), Chalice of Dawn (party heals 10% after victories), Gravewrought Coin (+80 starting gold), Eidolon Mirror (Warriors start battles with 25 Rage), Emberheart (fire & holy +20%).

10. Battle Screen & Controls

  • Layout: the camera shows the whole battle scene at 1:1 (sprites scaled up to compensate — heroes ×3.2, Chief ×3.9, bosses ×4.4). Burger menu (☰) top-left; initiative bar beside it; combat log top-right (scrolling, color-coded); heroes left, enemies right on the zone's own battlefield art (Forest / Scarlands); action bar bottom-center on the acting hero's turn; per-unit HP / resource bars, a Break meter with a numeric x/100 readout, status chips (hover for tooltips), and a bleed meter under each combatant. Rapid floating combat texts stagger vertically so they stay readable.
  • Action bar: Basic attack button; Abilities ▾ — a button list where hovering each entry live-previews its initiative cost on the bar (costs shown, unaffordable entries greyed); Items ▾. Guard no longer exists.
  • Burger menu: Restart Run (abandons to a fresh draft), Settings (overlay with volume + fullscreen — the battle isn't lost), Exit to Main Menu (run resumes from the last saved node).
  • Targeting: click a highlighted unit (cancel button available); single-target abilities auto-target when only one candidate lives.
  • Skill check controls: Spacebar or Left Click.
  • Feedback: floating damage text (crit pop-ups), hit flash + knockback, screen shake, lunge animations, Break hitstop + fracture flash + camera punch, per-event SFX (bow users — the Hunter and Orc Archers — get dedicated attack / impact / blocked sounds; the rest is placeholder procedural audio), tinted portraits + hover highlight (outline shader) linking the initiative bar to the field.
  • Music: menu track (main menu, draft, settings, relics, and spec choice — party setup stays on the menu theme), map track (map, party, shop — continues seamlessly between them; boosted +6 dB), battle track in combat. The boss-entry tune plays twice per zone arc: once over the fade to black after the final spec is confirmed (handing off to the map track), and once when a boss battle opens (capped at ~4s there, fading quickly into the battle track so the fight isn't kept waiting). Managed by the Music autoload; volume rides the master bus (Settings); the map track plays 6 dB hotter than the rest. Menu buttons share a click sound (Music.click()); potions have their own drink sound; Strike and Hack and Slash (per hit) have dedicated impact clips.

11. Other Screens

  • Party screen: hero list with tinted class icons beside each name, HP/Mana readouts and unspent-point highlights; detail page per hero: stats (with tooltip explaining derived values), ability chips (hover for numbers), rune equip toggles (2 max), and the run's generated talent tree with learn/rank-up buttons.
  • Shop (The Wandering Peddler): consumables column + one rune offer per party member; reached via the 6 shop nodes on every zone map.

12. Technical Reference

  • Scenes: main_menu, draft, spec_choice, map, battle, party, shop, settings, relics. All UI is built in code (no editor scenes).
  • Autoloads: Run (run state + saves), Settings, Music (looping stream player that survives scene changes; idempotent play()). Static data: Classes, Talents, Relics, Ability.
  • Saves: user://run_save.bin (auto after every node; versioned dictionary), user://relics.json, user://settings.cfg.
  • Balance tooling: DOD_AUTOPLAY=1 (one bot battle with debug prints), DOD_SIM=N (N max-speed battles + a stats report: win rate, damage shares, ability usage, roll rates), DOD_SIM_SPECS="berserker,cryomancer,inquisitor,beastmaster" (override the specs the bot plays — order: warrior, mage, cleric, hunter). Target ≈85% bot win rate.
  • Testing shortcuts: launch with DOD_DEBUG=1 to add a DEBUG section to the map burger menu — +200 gold, +3 talent points for everyone, full heal, jump to the boss tier, advance to the next zone, and Reroll Specs (refunds spent talent points, clears all specs, and reopens the awakening screen). The battle scene also runs standalone (godot res://scenes/battle.tscn) with a default party and no run state.
  • Sprites: 100×100 frame strips named Name_Idle/Walk/Attack01–03/Hurt/Death.png; new character art must follow this format. New assets arrive in "imported files/".
  • Combat pacing: global PACE multiplier 0.85 on battle waits.
