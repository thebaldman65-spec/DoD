DAWN OF DECAY — Master Design Document

The single authoritative reference for what is CURRENTLY in the game — it describes the present build only (the timestamp above is bumped on every edit); the history of changes lives in the changelog. Engine: Godot 4.7, all UI built in code.

1. Concept

A turn-based party roguelike. The world is being consumed by the Decay; the player commands the Untouched — four heroes immune to it — through zone after zone of corrupted enemies. Runs are short, buildcrafted, and repeatable: draft a party, awaken permanent specializations, climb a node map, defeat the zone boss, descend deeper. Death ends the run but feeds a permanent relic collection (meta-progression). Combat is timeline-initiative with a timing skill check on every action — the player's execution matters as much as their build.

2. Run Flow

Main Menu → Draft (pick 4 heroes + equip up to 3 relics) → Map (node climbing) → Battles / Rest / Loot → after the first victory, Spec Choice (permanent) → Party screen (talents, runes) → … → Zone Boss → next zone (party fully restored) → final boss → run complete.

  • Main menu: New Game, Continue (enabled when a save exists), Relics (collection viewer), Settings (master volume, fullscreen — persisted to user://settings.cfg), Exit.
  • Draft: heroes shown as sprite cards; click to select. Selection order = battle position (slot order also sets each hero's tint). One of each class — picking a duplicate moves it. Up to 3 unlocked relics may be equipped for the run.
  • Spec choice: offered per hero after the first victory. Three cards per class, each showing the spec name, its archetype in bold (mouseover for the archetype explanation), blurb, passive, and full ability details. The choice is permanent for the run.
  • Victory rewards: gold + talent points for every hero — 1 per fight, 2 per elite, 3 for a zone boss (rests and shops award none). The FINAL boss awards no talent points — points earned when nothing follows are unspendable; its relic is the prize. Fallen heroes return after a won battle at 20% max HP ("the Untouched refuse to stay down").
  • Defeat: the run ends, the save is cleared, back to a new draft.
  • Saving: auto-save to user://run_save.bin after every completed node AND after spec confirmation (including debug rerolls); Continue resumes at the map. Loading migrates members to newer fixed talent trees (points refunded) when a save predates them. Run end (win or wipe) clears the save.

3. Zones & the Node Map

Structure rules: every zone is a ladder of 10 tiers plus the boss tier. Each tier holds 3 nodes — 30 interconnected nodes total — and the player picks exactly one node per tier, so 10 nodes are interacted with before the boss. Node composition is a fixed deck per zone:

Effects speak a fixed verb vocabulary — gold / gold_pct / heal_pct / damage_pct (never kills: floors at 1 HP) / mana_pct / max_hp_pct / attack_pct (permanent for the run, applied at battle spawn) / talent_points / item / random_item / revive_pct (the fallen return) / relic_grant (random inactive relic; +40 gold when slots are full) — aimed by target selectors (party, random, lowest_hp, class:<key>) and gated by requirement conditions (min_gold, max_gold, zone_slot, has_item, spec_in_party, fallen_hero). Adding an event is a JSON edit; adding a verb is one handler. 16 events ship now (three zone-gated, two spec-gated, one needing a fallen hero); the schema is built for 40+. Seen events persist in the save and never repeat within a run until the pool exhausts.

Warbands are pre-rolled at map birth and scoutable: every combat node carries its warband from the moment the map is generated, and hovering the node shows the theme, the full lineup, and the band's damage-type identity — how many units resist a type and how many are soft to it ("Resists: Nature x3 / Soft to: Fire x2"). The boss escort is readable from tier 1, so resist counterplay can shape routing and talent picks all zone long.

The deck is shuffled and dealt 3 per tier (tier 1 is guaranteed at least one fight so runs open with combat). Connectivity is deliberately limited: every node links to its own column on the next tier, plus a 70% chance of ONE adjacent column — never all three. The player gets a route choice most tiers but can only drift one column per step, so reaching a specific elite or shop takes planning; every node keeps at least one inbound path so the map never strands. The boss tier is a single node.

Elites are the snowball engine: a skilled player routes toward them. On top of double talent points, an elite kill drops a rune for a random hero, a random consumable, and a bigger gold purse (80–100).

  • Zones — authored slots: a run is three zone slots, and each slot draws one zone from its own authored candidate pool — zones are designed FOR a position (openers are not finales), so a zone def carries its name, its boss, and a roster per slot it can host. The current pools run fixed: 1. Forest of Old (roster 1) → 2. The Scarlands (roster 2) → 3. Forest of Old as the finale (tougher roster 3 — behemoths walk the old woods). Random slot draws sit behind the DOD_ZONE_ROTATION=1 flag until each pool holds ~2 candidates; every zone keeps the same 11-tier ladder so the talent economy (~35 points/run) never shifts. Deeper-slot enemies are tinted redder, and the slot sets the stat multiplier (§4.3). The finale's boss — the Withered Warden again, by design — is the FINAL boss: the run ends on its death.
  • Zone completion: killing the boss awards a relic unlock, big gold, 3 talent points, and fully restores the party (HP and Mana) before the descent.
  • Map screen: zone art background, node ladder, Party button (shows unspent talent points), read-only Inventory dropdown, burger menu (Restart Run / Quit to Main Menu / Quit to Desktop), gold + party HP readout.

4. Combat System

4.1 Initiative timeline

Every unit sits on a shared timeline. After acting, a unit's next turn arrives after delay × 100 / speed time units (delay is the ability's initiative cost, listed in every tooltip; basic actions are 2.0, heavy abilities up to 6.0). Speed 100 is average. Slow status reduces effective speed to 75%; Quick Draw raises it by 50%. Some abilities shove the target down the timeline (delay_push). The initiative bar (top of screen, 14 slots, 38×53 portraits) always shows the coming order; hovering any individual ability re-sorts the bar with a gold "ghost" portrait showing where that cast would land your next turn. The ghost locks in when the ability is chosen and persists through targeting and the skill check.

4.3 Attack resolution pipeline

Per strike, in order: ability % × the attacker's current Attack × random variance (0.9–1.1) × grade multiplier × crit (×1.5; Sharpshooter passive ×2) × attacker modifiers × target modifiers × (1 − resist) × (1 − effective armor), minimum 1.

  • Attack (stat) & node scaling: every unit has an Attack stat, and every ability's damage is a PERCENT of the user's current Attack (a "45%" ability at 100 Attack hits for ~45). Base Attack comes from the spec's role — Damage 100, Tank 75, Support 50 (per-spec stat blocks are being filled in class by class). All scaling is LINEAR on the base value: heroes gain +2% of base Attack and +2% of base max HP per combat node won (fight/elite/boss); enemy scaling is zone-local — each zone replays its own tier ladder at +4% of base Attack and +5% of base HP per tier (1–11), multiplied by the zone's slot in the run: 1st zone ×1.0, 2nd ×1.5, 3rd ×2.2 (keyed by position, not identity — the Forest of Old is ×1.0 as the opener and ×2.2 as the finale; slots past the third continue the ~×1.5 step, so adding zones never touches the formula). Armor, Resistances, Speed, Constitution, Crit, Block, and Parry never scale. Damage-over-time effects (Burn 6%, Poison 3% per stack) snapshot the applier's Attack when they land. Battle tooltips show the computed damage numbers; the hero stat page shows the numbers AND the % scaling behind them.
  • Mitigation is itemized in the log: every landed hit reports what the defenses ate — "(nature resist -8)" for resistances, "(armor -12)" for armor, and "(WEAK! +9)" when a Weakness ADDED damage — alongside the parry/block source tags.
  • Resistances (stat): heroes carry a resistance per element — Fire, Frost, Nature, Holy, Shadow, Arcane — working exactly like armor but against that damage type (negative = weakness). Hover "Resistances" on the stat page to read them; per-spec values are being assigned class by class (all 0% until then).
  • Miss: 5% base chance (single-target, non-counter only); a Dazed attacker is 20% more likely to miss, a Blinded one 50% more. Attacks against an Elusive target (Canis/Aguila) are 25% more likely to miss. AoE never misses/parries. Multi-hit and random-hit attacks roll miss per strike — a missed hit never cancels the follow-up strikes.
  • Parry: only MELEE attacks can be parried — ranged attackers (Hunter and Mage among heroes; Orc Archers and Shamans among enemies) sail past the blade. Baseline is split by side — heroes parry at 5%, enemies at 2.5% — plus parry bonuses (talents, Parry Up). A spec's stat block can replace the hero baseline outright: the Swordmaster parries at 12%, the game's only parry-STAT character, exactly as the Warden is its only Block-stat one. A parried hit still lands but with 75% less damage AND 75% less Break damage (on-hit statuses can still apply); the log names the parry's source — reflexes, Sword Mastery, or Parry Up — e.g. "(parried -75% — Sword Mastery)". Parrying does not trigger an automatic counter. AoE cannot be parried; Broken units cannot parry; multi-hit attacks roll parry per strike.
  • Counter Attack (term): immediately answering a parry with a basic attack — a free action with no initiative cost that cannot chain. Granted only by specific effects (the Swordmaster's Riposte talent grants it).
  • Block (keyword): fully negates an incoming attack — 100% of the damage, the Break damage, and its on-hit effects. Governed by Block %, a SPEC STAT only pure tanks carry (currently the Warden: 10% base, +15% from Heavy Plating, plus Heavy Plating's climbing bonus — +8% per unblocked attack, cap +40%, reset whenever a Block lands; the Orc Shieldmaster also blocks at 5%). Guaranteed blocks come from Shieldwall charges — the Warden's own casts and the charges Interpose hands the party. Broken units cannot Block. A block flashes BLOCK and the log names its source — "(Shieldwall)", "(Heavy Plating)", or "(base Block)" — which matters: the Warden's Tenacity and Rally talents feed on Heavy Plating blocks specifically.
  • Armor Penetration (keyword): every % of armor penetration negates a % of the target's armor (currently granted only by the Berserker's Crushing Blows talent). It is NOT shown on the character screen.
  • Adjacent (keyword): the enemies DIRECTLY next to a target in formation order, one on each side (never the target itself). A dead neighbor NEGATES the adjacent bonus on that side — the effect does not jump past a corpse to the next living enemy. Splash effects that say "Adjacent" (the Warden's Sundering) hit at most those two enemies.
  • Cooldown (keyword, "cd"): the number of the user's turns before the same ability can be used again — "6cd" means unusable for 6 turns after use. Typical bands: basics 0, light hits 1–2, heavies/AoE 2–5, Resurrection 3. The remaining cooldown shows on the ability button ("CD n") and in its tooltip. Enemies do not use cooldowns at all — their kits are gated by resources and AI conditions instead.
  • Buff / Debuff (keywords): a DEBUFF is any negative status effect, a BUFF any positive one. Talents that count debuffs (Dominant Presence, Iron Will) use this classification.
  • Crit: 10% base + 25% vs Broken targets + 3% per Mage Resonance stack + talent/spec bonuses (+15% with Aguila summoned). Guaranteed: Ice Lance vs Frozen; a perfect Execute. Resonance builds only on the Mage's own casts — parry counters do not grant stacks.
  • Attacker modifiers: Resonance +15%/stack; Surge +20%; Empower +25%; Cripple −25%; Blood Frenzy up to +40% as HP falls; Seasoned Fighter +15% above half HP; relic bonuses (global +10% dragonbone; fire/holy +20% emberheart); Powershot +2% per 1% of the target's EMPTY Break bar; Overpower +0.5 per point of target Break; Arcane Cannon +7.5%/Resonance stack; Magi's Wrath +4%/Resonance stack; Fireball perfects at 25% of Attack.
  • Target modifiers: Shieldwall −50%; Exposed +15%; Seasoned Fighter −15% at or below half HP; Mage Resonance +5% damage taken per stack (the glass-cannon risk); Stabilized −10% per stack consumed.
  • Armor: flat % damage reduction. Fortify +10%; Broken ×0.7; Sunder ×0.65; Armor Penetration ignores a fraction.
  • Damage types (7): physical, fire, frost, arcane, nature, shadow, holy. Every enemy kind carries a deliberate resist AND vulnerability profile (see the bestiary §9) — themes inherit them, so a warband reads strong against some damage types and soft to others, and the theme name carries tactical information.
  • Vulnerabilities: a unit can be soft to a damage type — a negative resist, typically 25% extra damage taken from it. Hits on a vulnerability flash WEAK! over the target and are tagged in the combat log; nature-soft units also take amplified Poison ticks (and fire-soft units amplified Burn ticks). Vulnerabilities are counterplay, never hidden: they show on the map's warband hover BEFORE committing to a fight, and on every unit's nameplate hover in battle.
  • Barrier absorbs damage (not BD) before HP.

4.4 Break damage & Break

Attacks deal Break damage (BD) — damage against the Break meter — equal to the ability's Break damage (BD) value × grade multiplier (×1.5 on crits). Every unit's Break meter is a universal 0–100 scale with a numeric readout on the bar. Logged BD is the applied (post-Constitution) value, so the number always matches the meter; crits deal ×1.5 BD, which is why the same ability moves different meters by different amounts. Resistance comes from Constitution: incoming BD is scaled by 100/Constitution (100 = neutral; a 160-Constitution boss takes ~38% less Break damage; an 85-Constitution mage takes ~18% more). Constitution is set per specialization role (see §6), raised by talents and Poise runes. When the meter fills, the unit BREAKS: it loses its next turn, armor ×0.7, +25% crit chance against it, and enemies actively exploit Broken heroes with their hardest affordable attack. Bosses cannot be Stunned unless Broken (stuns fizzle with an IMMUNE flag). Breaking triggers hitstop, a purple fracture flash, and a camera punch. After the lost turn, the Break meter resets to 0. Ward halves incoming BD; the Devout's Devoutness talent cuts it 5% per rank; Bulwark of Fortitude negates it entirely.

4.5 Bleed & damage over time

  • Bleed is a 0–100 buildup meter (chip shows Bl##). Wounding attacks add buildup (Wildstrikes 35 always; Hack and Slash 25 at 50% per hit). At 100 the target bleeds out for 20% max HP and the meter resets. Bleedout damage ignores armor entirely.
  • Burn: 6% of the applier's Attack (snapshotted when it lands; ≈6 at 100 Atk) at the start of the afflicted unit's turn; ticks can crit using the caster's snapshotted crit chance. Burn counts as fire damage — fire resists reduce the tick and fire vulnerability raises it, exactly as nature does for Poison. Reapplication extends duration — every fresh Burn ADDS its applied turns to the running timer (a 3-turn Fireball on a burning target = +3 turns, announced with a "Burn +N turns" float).
  • Poison: 3% of the applier's Attack per stack (snapshotted; ≈3 at 100 Atk) at the start of the afflicted unit's turn. Poison counts as nature damage — nature resists reduce the tick (and nature vulnerability raises it). Stacks additively with no cap; every new application adds a stack AND refreshes the timer. Applied by Orc Archers' Poison Arrow (3 turns), the Withered Warden's Roots of Wrath (3 turns), and the Survivalist's Trapper passive (5 turns).
  • Renewal (15% of the caster's max health, snapshotted at cast) and Focus (status) +10 Mana at turn start.

4.7 Items in battle

The party inventory is shared and opens as a picker via Alt or the "[Alt] Items" button (Tab cycles, Space uses, X closes — see §10). Using an item does not consume the turn, but each hero may use only one item per turn. Bomb: 50 damage to all enemies. Health Potion: +40 HP. Mana Potion: +40 Mana/Rage. Revive Potion: fallen ally returns at 50% HP. Defense Potion: party gains Fortify (3 turns).

4.8 Enemy AI

Enemies hunt the most wounded hero 40% of the time and pick randomly otherwise; if any hero is Broken they exploit it with their hardest affordable hit. Mocked enemies must attack the taunting Warrior — a taunt also overrides support casts. Support behaviors run before attacks: the Orc Shaman casts Healing Wave on the most wounded ally under 40% HP (friendly tanks and healers first); the Orc Shieldmaster ALWAYS casts Shielding when no ally carries its ward (lowest-HP ally first, itself included); the Withered Warden has a 60% chance to cast Wild Growth on the most wounded of its warband (itself included) when someone is below 70% HP. The Chief and the Ash-Wrought Tyrant build and spend Rage like a Warrior.

4.9 There is no announcer

All battle information lives in the scrolling combat log (top right) and floating combat text. No banner text appears at the top of the battle.

5. Heroes

All ability damage is a % of the user's Attack (see §4.3); the flat numbers in the kit lists below are the values at the class/spec base Attack, before node scaling. Shields stay flat, and ability healing scales off the CASTER's max health (Heal 40%, Renewal 15%/turn, Hymn of Hope reads each target's own health) — a beefier healer heals harder.

All four classes are drafted every run (one of each). Sprites currently share the Soldier sheet, distinguished by slot tints (white / blue / gold / green); distinct art is arriving spec by spec. Own art in-game so far (specs listed in battle.gd's SPEC_ART table, always shown untinted in original colors): the Pyromancer — a hooded torch-bearer at the OFFICIAL template size (236px frames, 1:1 scale; static east-facing pose until his animations exist) — and the Berserker — a fur-cloaked axeman with idle / walk / attack animations and his own portrait, at the legacy 124px @1.25× size until re-generated at the template (his hurt, death, and extra attack clips are also pending; the game falls back gracefully meanwhile). 5.0 Class passives

Each CLASS carries one passive, active for every spec of that class (and before awakening). Shown as a ◆ chip in battle and on the party screen.

  • Warrior — Threatening Presence: enemies are 20% more likely to attack the Warrior (weighted into their random target picks).
  • Cleric — Holy Conduit: all healing the Cleric receives is increased by 15%.
  • Hunter — Tracker: always attacks first in every fight.
  • Mage — Evocation: regenerates an additional 10 Mana per turn (22 total).

5.1 Resource mechanics

  • Rage (Warrior): starts at 0. +5 at the start of each of his turns; +10 whenever he is hit; every attack builds Rage (Strike 20, all spec/talent attacks 10); Perfect Strike +10.
  • Mana (Mage/Cleric/Hunter): +12 at the start of their turns; the Hunter's Perfect basic adds +10; potions/Rally restore more.
  • Focus (SHARPSHOOTER passive, 0–100, green second bar): +20 per consecutive attack on the same enemy (Muscle Memory adds more), 0 on switching targets (halved under Unwavering), up to 50 retained on a kill; talents move the cap to 150 (Deep Focus) or 50 (Spray of Arrows). Every point: +0.5% crit chance. Spent by Coup de Grâce and One Shot.
  • Mercy (HOLY passive, 0–5): only the Holy spec has the bar. +1 stack whenever a party member falls below 50% health (any damage source; crossings count each time). Each stack held: +5% healing done. Stacks are SPENT on Hymn of Hope (1), Divine Plea (2), and Resurrection (1) — costs are paid before the cast resolves, so a spender heals with what remains — or on Empowerment: the ✦ Empower toggle (hotkey C) arms the next supporting cast for +1 extra stack and a bonus effect. Empowered casts forgo their perfect bonus. Talents move the economy: the ceiling (Martyr's Vigor, to 6/7), the opening stacks (Zealous Light), and the Empower surcharge itself (Ardor and Avatar of Mercy can waive it — see §7).

7. Talents

Economy: talent points come from victories alone — 1 per fight, 2 per elite, 3 per zone boss (rests and shops award none; Waystone +1 at run start). Points bank until spent on the Party screen.

Every tree is a lane tree. Ten are purpose-designed on the lane framework (Berserker, Swordmaster, Warden, Holy, Devout, Occultist, Pyromancer, Sharpshooter, Survivalist, Beastmaster); the other two are Batch 31 conversions of their classic grids awaiting the same treatment.

Lane framework rules: a tree is three LANES of seven nodes — each lane a playstyle — plus three CAPSTONES of which only ONE may ever be taken. Node pricing: the Nth distinct node bought costs ceil(N/3) — 1,1,1,2,2,2,3… — while extra ranks in an open node always cost 1, so roughly a third of the tree fits in one run. Exclusive pairs bar each other but stay visible, greyed with the reason — the player must see the door they closed. Tooltips show the live cost and lane requirement.
Two gating models exist. Points-gated trees (Beastmaster and the two conversions) open a lane's tier 2 at 3 points spent in that lane, tier 3 at 6, the capstone at 8. Node-gated trees (Berserker, Swordmaster, Warden, Holy, Devout, Occultist, Pyromancer, Sharpshooter, Survivalist) open tier 2 at 2 NODES bought in the lane, tier 3 at 4, the capstone at 6 — with the escalating cost curve, node count is the stable gate a player can actually plan against.

8. Economy

  • Gold: start 60 (+80 with Gravewrought Coin). Fight 25–35, elite 80–100, boss 110–130.
  • Consumable prices: Health 30, Mana 30, Bomb 45, Revive 80, Defense 40. Starting inventory: 2 Health, 1 Mana, 1 Bomb, 1 Revive, 1 Defense.
  • Runes (run-scoped gear, bought at the Peddler or dropped by elites): rarity roll 60% Common (×1, 50g, "Cracked"), 30% Rare (×2, 100g, "Polished"), 10% Epic (×3, 160g, "Radiant") over templates: +10 max HP / +2% armor / +4 Speed / +12 Constitution / +2% crit / +8 max Mana (per rarity multiplier). Each hero can equip 2 (toggled on the party screen); shop offers avoid duplicates per hero.
  • Relics (permanent meta): one random unlock per boss kill, stored in user://relics.json; up to 3 equipped per run at the draft (scrolling shelf; events can slot a run-scoped extra via relic_grant). Pool: 25 relics — 17 common, 8 rare (◆) — every effect expressed through an audited hook vocabulary (19 hooks, listed atop relics.gd: run-start gold/points/items, party stat boosts at battle spawn — attack, typed damage, max HP, armor, speed, crit, Constitution, resistances, resource floor — victory heal/mana/gold, gold-find, rest bonus, shop discount, elite loot). Scalar hooks SUM and dict hooks merge across the equipped set, so stacking is well-defined. Adding a relic on an existing hook is pure data. Highlights: Waystone Shard grants +3 talent points; the elemental trio (Emberheart / Frostbound Sigil / Nightbloom Charm) covers all six damage schools; Prism Veil gives 10% resistance to every element; The King's Ledger compounds gold.
  • Persistent profile (user://profile.json, outside the run save): counts runs started/completed/wiped per spec, bosses killed by kind, events seen (with repeats), and zones cleared. Chronicle only — it gates nothing; the Relics screen shows the tally ("Cycles survived / lost / Events witnessed"). 10. Battle Screen & Controls

  • Layout: the camera shows the whole battle scene at 1:1 (legacy sprites scaled up to compensate — Soldier heroes ×3.2, Chief ×3.9, bosses ×4.4, Berserker ×1.25; the Pyromancer's template-size art runs at true 1:1). The battlefield art (Forest / Scarlands) is zoomed out as far as the screen allows — the smallest scale that still fills the 1280×720 view (+ shake margin); any smaller would show void at the edges, so making scenery read smaller from here means new background art at the template density. Burger menu (☰) top-left; initiative bar beside it; combat log top-right (scrolling, color-coded, with a small – / Log button to hide or restore it); action bar bottom-center on the acting hero's turn. Each party is grouped tight (heroes ~x350–430, enemies ~x905–990) and every unit's readouts live on a 144px nameplate in a stack behind its party — heroes' plates along the LEFT edge, enemies' along the RIGHT. A plate holds a portrait (dedicated art if the unit has it — the Berserker does — else a sprite close-up), the unit's name, HP bar, resource bar(s), Break meter with numeric x/100 readout, and its status chips (hover for tooltips; Bleed buildup is a chip). Hovering a plate (or a body while targeting) shows the unit's resist card — what it resists and what it is vulnerable to — so counterplay is never hidden information. The battle UI is deliberately compact (144px plates, 240px log, compact action bar and initiative portraits) so the field dominates the screen. The acting unit's plate glows with a gold border — that IS the turn indicator; hovering or Tab-targeting a unit lights its plate too, and hovering a plate highlights its unit on the field. A dead unit's plate dims. Plate visuals are plain placeholders until the final UI asset set arrives. Rapid floating combat texts stagger vertically so they stay readable. The combat log details status effects: Bleed lines show buildup and meter value, Poison lines show stack counts and damage per turn, and DoT ticks report their stack multiplier.
  • Action bar: Basic attack button; Abilities ▾ — a button list where hovering each entry live-previews its initiative cost on the bar (costs shown, unaffordable entries greyed); [Alt] Items — opens the item picker.
  • Ability hotkeys: Q / W / E / R / A / S / D / F map to the ability MENU slots in order — Q is always the basic attack, the Beastmaster's "Summon Companion" picker holds W, and the remaining abilities follow in kit order. Each button shows its key, e.g. "[W] Bloodlust". A hotkey is ignored when the ability is unaffordable or gated (Stabilize without a Resonance stack, Kill Command without a living companion, Resurrection with nobody fallen), and hotkeys only work while the action bar is open — never during targeting or a skill check.
  • Tab: while choosing an action, Tab opens/closes the Abilities list (browse with the mouse or fire a hotkey). After an ability is chosen, Tab cycles through the available targets (the highlight and ▼ marker follow) and Space or Enter confirms the highlighted one — a full keyboard turn is Q/W/E/R… → Tab → Space → Space on the skill check. Clicking still works everywhere.
  • X cancels: whenever a Cancel button is on screen — during targeting, a cancellable skill check, or an open picker — pressing X triggers it (the buttons say so: "✕ Cancel (X)").
  • Alt — items: Alt toggles the shared item inventory picker (the "[Alt] Items" button opens the same window): Tab cycles the usable items, Space uses the highlighted one, X closes. One item per hero per turn, and items never consume the turn.
  • C — Empower (Holy Cleric): toggles the ✦ Empower button on the action bar while at least 1 Mercy is held — the next Heal / Renewal / Hymn / Resurrection / Divine Plea spends +1 Mercy for its bonus effect (and forgoes its perfect bonus). The toggle disarms after the cast and at the start of every turn.
  • Space continues: on a victory screen, Space (or Enter) presses the primary button — Continue / Descend / New Run. Defeat screens still require a click.
  • Summon Companion sits at the TOP of the Beastmaster's ability list on hotkey W. Selecting it (key or click) opens the beast picker — a small window listing Ursus / Canis / Aguila with costs: Tab cycles the options (unaffordable beasts are skipped and greyed), Space summons the highlighted one, X closes the picker, and clicking works as always. With a living beast out, the entry reads Swap Companion and the picker offers swaps instead (10 Mana, shared 2-turn cooldown; the active beast is greyed out). Summoning or swapping in Aguila then asks for a target — its arrival dive. Call of the Wild (when owned) joins the picker as a fourth entry. The remaining abilities take the following hotkeys in kit order (Hunter's Instinct E, Kill Command R; boss-trophy abilities follow as they are earned).
  • Burger menu: Restart Run (abandons to a fresh draft), Settings (overlay with volume + fullscreen — the battle isn't lost), Exit to Main Menu (run resumes from the last saved node).
  • Targeting: click a highlighted unit (cancel button available); single-target abilities auto-target when only one candidate lives.
  • Skill check controls: Spacebar or Left Click.
  • Feedback: floating damage text (crit pop-ups), hit flash + knockback, screen shake, attack movement (units with real locomotion art — the Berserker — walk to melee range and back with their walk animation, facing their direction of travel; everyone else does the short lunge), Break hitstop + fracture flash + camera punch, per-event SFX (bow users — the Hunter and Orc Archers — get dedicated attack / impact / blocked sounds; the rest is placeholder procedural audio), and hover highlighting (outline shader + lit nameplate) linking the initiative bar, the plates, and the field.
  • Music: menu track (main menu, draft, settings, relics, and spec choice — party setup stays on the menu theme), map track (map, party, shop — continues seamlessly between them; boosted +6 dB), battle track in combat. The boss-entry tune plays twice per zone arc: once over the fade to black after the final spec is confirmed (handing off to the map track), and once when a boss battle opens (capped at ~4s there, fading quickly into the battle track so the fight isn't kept waiting). Managed by the Music autoload; volume rides the master bus (Settings); the map track plays 6 dB hotter than the rest. Menu buttons share a click sound (Music.click()); potions have their own drink sound; Strike and Hack and Slash (per hit) have dedicated impact clips.

12. Technical Reference

  • Scenes: main_menu, draft, spec_choice, map, battle, party, shop, settings, relics. All UI is built in code (no editor scenes).
  • Autoloads: Run (run state + saves), Settings, Music (looping stream player that survives scene changes; idempotent play()). Static data: Classes, Talents, Relics, Ability.
  • Saves: user://run_save.bin (auto after every node; versioned dictionary), user://relics.json, user://settings.cfg.
  • Balance tooling: DOD_AUTOPLAY=1 (one bot battle with debug prints), DOD_SIM=N (N max-speed battles + a stats report: win rate, damage shares, ability usage, roll rates), DOD_SIM_SPECS="berserker,cryomancer,inquisitor,beastmaster" (override the specs the bot plays — order: warrior, mage, cleric, hunter), DOD_SIM_ENEMIES="boss,shieldmaster,shaman" (force the enemy lineup in autoplay/sim/standalone battles), DOD_SIM_TALENTS="bz_bloodcraze:3,wd_toughness:2" (force-learn talents on bot heroes whose spec tree holds the id), DOD_SIM_ABILITIES="Resurrection,Divine Plea" (append pending talent-gated abilities to the bot hero whose spec owns them — Holy only for now), DOD_ENEMIES_OFF=1 (arm the "Enemy attacks OFF" debug toggle from the environment). Autoplay debug runs echo every combat-log line to stdout as "[LOG] ..." so headless tests can grep them; status expiries print as "... fades from ..." lines. Target ≈85% bot win rate.
  • Testing shortcuts: debug tools are ALWAYS available in dev (unexported) builds; exported builds require DOD_DEBUG=1. The map burger menu gains a DEBUG section — +200 gold, +200 talent points for everyone, full heal, jump to the boss tier, advance to the next zone, Reroll Specs (refunds spent talent points, clears all specs, and reopens the awakening screen), and an All Spec Abilities Unlocked toggle (while checked, battles spawn with every talent-gated and trophy ability pre-granted — session-scoped, never saved, default OFF so normal play and sims measure real gated progression; headless runs arm it with DOD_SIM_GRANT_ALL=1). In battle, a DEBUG ▾ menu (bottom-right) offers: Full Restore (HP/resources/secondary for the party), a Cooldowns OFF toggle (while checked, hero abilities never go on cooldown; existing cooldowns clear on enabling — enemies carry none), an Enemy attacks OFF toggle (enemies skip their turns while checked), and a turn lock — pick a hero and every HERO turn is theirs until you unlock (re-select them) or lock a different hero, while enemies keep attacking on their own turns (combine with Enemy attacks OFF to silence them); built for testing one hero's kit under fire. The displaced heroes' clocks advance as if they had acted, so the initiative timeline keeps flowing. The battle scene also runs standalone (godot res://scenes/battle.tscn) with a default party and no run state.
  • Sprites: horizontal frame strips named Name_Idle/Walk/Attack01–03/Hurt/Death.png (square frames; the stock sheets are 100×100, but units accept any frame size via the frame_size config — the Berserker sheet is 124×124, the Pyromancer 236×236). Partial sheets are fine: missing Attack02/03 replay Attack01, missing Hurt/Death hold the idle frame, and a single-frame Idle (the Pyromancer today) simply stands. Dedicated portraits are Name_Portrait.png (used on the nameplate, initiative bar, and party list). New assets arrive in "imported files/" (animated GIFs get converted to strips; 8-direction rotation GIFs — the east-facing frame is extracted).
  • Resolution template: all character art matches the Pyromancer — a standing figure ≈110–120px tall inside a 236px frame, rendered at 1:1 (never scaled), original colors. The Berserker (124px @1.25×) is legacy-sized and should be re-generated at the template when convenient. Battle backgrounds: authored at ≈1280×720 (up to ~1670×940) and shown at/near native size — never blown up.
  • Combat pacing: global PACE multiplier 0.85 on battle waits.
