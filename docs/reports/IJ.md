## §2 — CONVERTED, AND REPAIRED

### §2a — THE RESOLVER, AND THE DOORS

`Classes.resolve_figures(text, fields)` replaces a token with a value: `{=Battle.VESPERS_PCT*100}` reads a constant of a game script
(`Classes.FIGURE_SOURCES`: Ability, Battle, Classes, Relics, Run, Runes, Talents, Unit) times an optional scale; `{=@damage}` reads a
field of the entry the text belongs to, a dotted path walking dicts and arrays; `{=@damage*Ability.GRADE_DMG_MULT.perfect}` is one
reference times another. A value prints whole if whole, else to two places. **A token that names nothing stays visible and
`push_error`s** — it cannot pass silently. **It is applied at six doors and nowhere else**: `Ability.make` (a card's words and
Perfect), `Runes._load`, `Glossary._load`, `Classes.engine_desc` (a core rune's rule), `Talents.desc_for` and `Relics.desc_of` (new,
and every relic surface reads it: the unlock card, the relic screen, the draft screen's relic tooltips). A code-held table — the
status chips, the potions — formats its figure inside its `const`, which GDScript evaluates at compile time. **The strike's grade
multipliers were two literal tables in `battle._resolve`**; they are `Ability.GRADE_DMG_MULT` and `GRADE_BD_MULT` now, and the strike,
every Perfect token and the skill-check hint read them.

> - **MAG** — a magnitude: a number, a percentage, a multiplier (*double*, *half*, *a quarter*, *x2.5*), a cap or floor.
> - **DUR** — a duration or count of turns (*for 3 turns*, *next turn*, *battle-long*).

>   payload/field value, a variable the code computes, a name read off data (`ab.display_name`, a rune's `name`). Example:
